## 5. Lessons learned (apply these)

- **Orphan detection**: ALWAYS grep `packages/runtime-core/src/application/`,
  `packages/runtime-core/src/integration/`, `packages/runtime-core/src/operations/`,
  plus `tests/*`. The session's first F1 attempt missed
  `anchor-candidate-service.ts` consuming `@masterpiece/creative-production-runtime`
  because that import is not in `apps/*`.
- **Atomic commits**: when one deletion requires import-site rewrites
  elsewhere, `git add` reports "did not match" on the deleted files
  silently. Always `git diff --cached --stat` before `git commit`,
  and `git commit --amend` if the staged set is incomplete.
- **Pre-commit gate**: check CRLF/LF + BOM + typecheck + build before
  every commit. `patch` tool may rewrite unchanged lines to a
  different line-ending; verify with `git diff --stat` and a byte
  count (`node -e "const b=fs.readFileSync(f); ..."`) instead of
  trusting visual diff.
- **Whitespace correctness for non-ASCII**: never use PowerShell
  `Set-Content -Encoding UTF8` for files with CJK content (system
  codepage = GBK mangles it). Use `write_file` tool or
  `[System.IO.File]::WriteAllText(..., [System.Text.UTF8Encoding]::new($false))`.
