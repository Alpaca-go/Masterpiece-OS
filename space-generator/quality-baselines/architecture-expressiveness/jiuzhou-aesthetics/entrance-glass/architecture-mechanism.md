# Architecture Mechanism — EntranceGlass

> **基准（benchmark）说明**：本文描述旧链路曾经产出的 S 级空间机制，用于 R8.5 评估"新版本是否能复现同等级别的空间结构机制"。  
> **不用于**复制玻璃幕墙、走廊形状、接待台。  
> **来源锚点**：`JZMX-ARCH-02-EntranceGlass`（anchor registry，imagePath 真实可用，provenance 见 `provenance.json`）。

---

## 1. 核心空间机制（Core Spatial Mechanism）

```
exterior
  → full-height glass transition
    → visual penetration
      → reception
        → deeper interior
```

**一句话表述**：街道与室内通过一面整高玻璃幕墙形成视觉连续；窄框走廊作为缓冲，把视线引入接待台，再继续向更深的内部空间渗透。

**机制层数**：5 层。

---

## 2. 评估重点（Evaluation Anchors）

| # | 检查点 | 是否属于"建筑机制" |
|---|---|---|
| A | 内外形成连续空间关系（玻璃不只是立面装饰） | ✔ |
| B | 入口是建筑体验的一部分（不是简单开门） | ✔ |
| C | facade → circulation → interior 的完整逻辑 | ✔ |
| D | 玻璃的窄框 / 整高 / 视觉穿透三选一以上具有机制性 | ✔ |
| E | 缓冲走廊承担空间序列组织（不是过道） | ✔ |

5 项全过 = 5/5。

---

## 3. 对新版本的要求

**允许**：从 V5 字段 derive 5 层机制描述。  
**禁止**：固化"全高玻璃 / 弧形天花"为 brand 必选；其他品牌（YJLF）需要"半透明但非玻璃"的等价机制。
