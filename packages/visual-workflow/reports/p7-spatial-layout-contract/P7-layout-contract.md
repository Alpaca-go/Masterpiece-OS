# P7 空间布局契约

这是项目级语义契约，不是已启用的布局引擎。字段已网页确认，最终Prompt表达尚未通过。

| 节点 | 职责与可读证据 | 关系 |
|---|---|---|
| 开放入口与到达 | 入口斜向直接读出主厅、开放地面与退让框景 | 直接通接待，不以巨墙/玻璃房阻挡 |
| 完整主接待台 | 服务正面、员工工作侧、访客接近面 | 主要商业锚点，与候客横向相连 |
| 成组候客 | 沙发、单椅、小桌及可坐可绕行空间 | 与接待同厅，向面询递进 |
| 单个边缘半开放面询 | 一张独立工作台分开操作侧与顾客侧，两侧各一椅、椅面隔台相向，转向显示器可供共看 | 局部短界面保护隐私，不挤占主厅 |
| 后续私密入口 | 面询之后错位遮挡，仍能读出服务转场 | 治疗活动、床及私室内部不入镜 |

视觉顺序为完整开阔主厅→接待锚点→候客→边缘面询→私密转场，各有可用空间，主要通行不被艺术或家具截断。左前景不得以新大墙替换旧围合，不回到窄入口小房间、密集门廊或酒店组织；不靠重复家具、营销架或前台面部广告屏补功能。

珠光系统必须连续连接建筑侧界面及局部上部边界，以透景转折参与候客到面询的空间节奏。固定薄边、少量薄层、真实层间深度和克制弱紫虹彩；不跨厅、不包裹整个面询，也不退为普通屏风、贴片或巨型贝壳墙。

允许改变曲率、辅助层数、反射细节和自然光交互；不锁米数、角度、百分比、像素或强制左右位置。P6完整前台/候客原句、色彩材料灯光字段逐值冻结，Logo和准确文字继续留待后期。屏幕只要求非识别性浅色皮肤纹理/面部分区/比例示意，排除解剖、诊断数值、病例、个人信息及疗效。
