## 设计动作

1. **木框玻璃隔断 + 木刻空心大字**：卡座区用浅木框玻璃分隔，木框上装 15–20 厘米厚的木刻空心字（“吃山/山货”类），字既是隔断也是招牌。
2. **竹编大吊灯做主视觉**：直径接近桌宽的竹编碗形吊灯垂在每张桌上，灯罩内藏光源，光只落在桌面。
3. **橙色桌布 + 白色山形印花**：每桌同款橙底白纹桌布，橙色成为最大的色块；桌布是消耗品也是识别物。
4. **入口/通道侧做“山货货架”**：整面浅木货架，摆玻璃罐（干花、豆、米、菌）与扎捆药材/茶包，货架打暖光灯带。
5. **用“秤”做装置**：木架下悬挂老式盘秤，盘里放松果/香料，把“市集称重”的动作搬进空间。
6. **红菱形菜名牌**：红纸/红底菱形牌写菜名或食材，贴在竹编灯罩与墙面上，是最便宜的“菜单”。
7. **文化石矮墙 + 浅木沙发**：矮墙只做到腰高，分隔又通透；座位用浅木框 + 米白布艺。
8. **物料用白瓷 + 橙色山形印**：碗、盘、杯、纸巾统一白底橙纹；品牌页另做木刻动物印章（牛、猪、鸡、鱼、花）做延展。
9. **门头用砖墙 + 木格栅 + 白字**：砖墙做底，浅木格栅压边，白色字标“吃山 乡村市集”，旁边直接摆货架与立牌。

## 成立前提（均为推断）

- 商场允许明火/排烟条件另有要求；本案例的“货架 + 陈列”不依赖明档，可复制性强。
- 有稳定的山货/菌子/药材供应链，货架陈列才不是空壳；否则罐子会变成装饰道具。
- 橙色桌布是高频更换的消耗品，需要洗涤/更换预算；换成不可洗材质会显廉价。
- 竹编吊灯尺寸大、位置低，要求层高足够、桌面排布规整；小桌密排会撞头。
- 木刻字隔断依赖木工精度，现场手工难复现；异地复制要找工厂预制。

## 禁止 / 误用

- 不是“物产型”品类（如日料、西餐、咖啡）不要用货架 + 玻璃罐 + 秤，会变成杂货铺。
- 层高不足、桌距过密时不要用大直径竹编吊灯，会压视线、挡传菜。
- 橙色桌布在大面积使用时会让空间显“快餐”；做中高端云南菜要降饱和或改局部。
- 商场消防对竹编、干花、纸牌有要求；不要堆到喷淋与烟感下面。
- 不要直接复制“吃山”字标、山形标志、木刻动物印章与红菱形菜名牌的版式。
