# S4.1 Host Dependency Map

## Current Web startup

```text
npm run web:dev / npm run web:smoke
  -> apps/desktop/scripts/run-web-*.mjs
  -> electron-vite dev
  -> Electron main: apps/desktop/src/main/index.ts
  -> BrowserWindow (Web renderer)
  -> Local HTTP RPC: web-rpc-server.ts
  -> handler map in index.ts
  -> Desktop-owned runtime service graph
  -> Shared Core facades
```

## Process and spawn audit

- `run-web-dev.mjs` spawns `electron-vite dev`.
- `run-web-primary-smoke.mjs` spawns `electron-vite dev` and passes an Electron user-data directory.
- The Electron main process creates the renderer `BrowserWindow` and starts the RPC server.
- No CLI process is spawned for analysis; CLI v5 is dynamically imported as a module.
