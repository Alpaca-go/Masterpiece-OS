## 设计动作

1. **布灯笼阵列做主光**：米黄布方形灯笼成排悬吊，布面印红字与图案，灯距密、位置低，把光控制在桌面以上、天花以下，天花本身保持暗。
2. **做旧水泥墙上写白色草书大字**：整面墙做洗白/斑驳水泥，白色大字横贯，字与墙同色系只在明度上拉开。
3. **用蓝紫晶格做“碎玻璃”装饰**：在墙面与通道之间嵌一片密集的菱形/晶格构件（材质未知），作为唯一的高饱和冷色块。
4. **红漆门框 + 红底白字双行招牌**：“市井老火锅 / 就吃辣三俏”，红漆框做成“老门洞”，把入口做成一个画框。
5. **绿玻璃小格窗 + 花格砖矮墙**：墙面嵌旧木窗与绿色玻璃小格，另做花格砖矮墙做分区，制造“老屋改造”的记忆。
6. **深木方桌 + 条凳，桌距紧**：不做软包、不做隔断，靠灯笼与墙面做气氛，翻台靠密度。
7. **物料走搪瓷 + 铁皮 + 老海报**：搪瓷杯（红字黑边）、纸杯、铁皮牌、老广告贴纸、报纸感的联排海报；色只有红、米白、黑。
8. **海报系统统一“一炉碳火/鲜货/真材实料”的短句 + 插画**：鱿鱼、肥牛、内脏做黑白版画感插画，配红底或米底。

## 成立前提（均为推断）

- 层高足够挂低垂灯笼阵列，且布灯笼不挡桌面视线与传菜动线。
- 火锅油烟大，布、纸、木都是吸味材料，必须有强排烟与可拆洗方案；否则半年就会油腻发黑。
- 客群接受“旧、暗、挤”的老店感；做清汤锅、家庭客、商务客时不成立。
- 商场消防允许布艺灯笼与明火/碳火（多数商场不允许碳火，需改电炉）。
- 老海报、铁皮牌、绿玻璃窗可从旧货渠道稳定采购，否则会变成廉价仿旧。

## 禁止 / 误用

- 高端火锅、清汤锅、日式涮涮锅不要用这套“红 + 旧 + 暗”，会显脏、显廉价。
- 层高低于 3 米的商场店不要做低垂灯笼阵列，会压到视线与排烟口。
- 消防不允许明火/布艺吊挂的场所，不要照搬“碳火泥炉 + 布灯笼”。
- 不要用大面积白色草书墙 + 晶格，除非墙面本身够长；小墙面会被字压碎。
- 不要直接复制“辣三俏”字标、铁皮牌文案、老广告贴纸与“市井老火锅”这句定位。
