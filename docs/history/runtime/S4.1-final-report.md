## Blocking evidence

- `apps/desktop/src/main/index.ts` owns at least 123 direct handler registrations plus image-generation registrations.
- `apps/desktop/src/main` contains 28 service-named TypeScript files.
- Project storage, analysis orchestration, image-generation orchestration and creative production remain active Desktop-path business services.
- A compliant Node host may not import these paths.
- Moving the complete graph and its shared types is a substantial core/runtime ownership migration, not a host-only extraction.
