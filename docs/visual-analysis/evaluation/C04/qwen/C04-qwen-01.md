## 2. 视觉系统提取（颜色 / 字体 / 构图 / 材料 / 跨触点一致性）

### 2.1 颜色系统 (Color Palette)
*   **主色 (Primary)**：**中国红 (Red)**。用于背景色块、Logo 底色、重点文字。传递热烈、食欲、传统的川菜印象。
*   **辅色 (Secondary)**：**黑 (Black)** 与 **白 (White)**。
    *   黑色用于灯笼、海报深色背景，营造高级感或夜间视觉效果。
    *   白色用于文字反白、白底海报，保持清洁感。
*   **点缀色 (Accent)**：食物本身的**褐色**（牛肉/汤汁）、**绿色**（香菜/葱花）、**米色**（编织垫/砂锅纹理）。

### 2.2 字体系统 (Typography)
*   **标题/品牌字**：中文“冯烫烫”使用**行楷/手写书法体**，强调“冯”姓的人情味和传统手艺感。
*   **英文/装饰字**：**粗衬线体 (Slab Serif)**，类似 Rockwell 或 Memphis 风格。
    *   实心用于“FENG TANG TANG”。
    *   **空心描边 (Outline)** 用于“QIAOJIAO BEEF”，增加现代设计感和视觉层次，避免画面过于沉重。
*   **正文/标语**：**粗黑体/无衬线体**，确保在远距离（如海报、灯笼）的可读性。

### 2.3 构图与排版 (Composition)
*   **上下分割式**：常见于海报。上部为食物特写+Slogan，下部为红色色块承载 Logo 和详细信息。
*   **居中对称式**：用于灯笼设计，强调品牌的正统感。
*   **图文叠加**：在食物摄影上叠加巨大的空心英文“QIAOJIAO BEEF”，形成前后景深，增加视觉冲击力。

### 2.4 图像与材料风格 (Imagery & Material)
*   **摄影风格**：高食欲感、微距特写。强调**热气 (Steam)**、**汤汁的光泽**、**肉质的纹理**。
*   **道具**：传统**砂锅**、**木勺**、**粗陶碗**、**编织餐垫**、干辣椒面。这些元素强化了“市井”、“传统”、“现做”的感觉。
*   **材质应用**：
    *   **灯笼**：红色和黑色纸灯笼，非常符合中式餐饮的街头氛围。
    *   **海报**：光面或哑光印刷，配合墙面展示。

### 2.5 跨触点一致性
*   **高度一致**：从海报到灯笼，再到 VI 展示页，Logo 组合、字体、红色色块、核心 Slogan 的复用率极高。
*   **变体应用**：提供了红底白字、黑底白字、白底黑字等多种组合，适应不同背景环境。

## 3. 设计决策与建议（Reference First / Space / Packaging 角度）

### 3.1 Reference First (参考与风格定位)
*   **风格定位**：**“新中式街头快餐”**。它保留了传统川菜馆的热闹（红色、灯笼、书法），但通过现代排版（英文大字、网格系统、空心字）提升了品牌的时尚感和标准化印象。
*   **参考建议**：在后续设计中，可参考现代面馆（如和府捞面）或新式小吃品牌的视觉逻辑，保持“传统内核 + 现代外壳”。

### 3.2 Space / Environment (空间与触点)
*   **灯笼应用**：红黑双色灯笼非常适合挂在店门口或室内。建议在实际落地时，注意灯笼的照明效果，红色灯笼在夜间应透出暖光。
*   **墙面海报**：图片素材展示了海报在瓷砖墙面的效果。建议在实际门店中，使用**亚克力展板**或**灯箱**形式，提升质感。
*   **明档展示**：跷脚牛肉通常在明档售卖。视觉系统应延伸到**档口招牌**、**价目表**（需清晰展示“小碗牛肉”的价格优势）。

### 3.3 Packaging (包装延伸)
*   **碗身/杯身**：虽然图片未展示，但“小碗牛肉”是核心卖点。建议在盛装牛肉的**碗/杯**上印制“冯”字 Logo 和“QIAOJIAO BEEF”空心字。
*   **打包袋/贴纸**：外卖场景中，使用红色打包袋或封口贴，强化品牌色。
*   **小吃搭配**：既然强调“川菜小吃巧搭配”，视觉系统中应预留展示卤菜、小吃（如钵钵鸡、红糖糍粑等）的版面，保持风格统一。

## 4. 限制与不确定性

*   **字体版权**：需确认“冯烫烫”手写体及英文粗衬线体的具体字体文件及商业授权情况。
*   **“非遗”资质**：图片中出现了“非遗”印章，需确认品牌方是否真实拥有非物质文化遗产相关认证，以免涉及虚假宣传。
*   **具体色值**：图片中的红色在不同材质（灯笼纸 vs 印刷海报）上会有色差，需输出标准的 VI 色值（CMYK/RGB/Pantone）。
*   **产品实物差异**：海报中的牛肉看起来非常精致，实际出餐需尽量还原摄影中的“热气”和“分量感”，避免“图文不符”。
