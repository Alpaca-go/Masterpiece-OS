# S4.1R Target Runtime Map

Status: `PASS`

```text
apps/web (Primary Renderer)
  -> HTTP RPC / SSE
apps/web-runtime (Node Host + Node adapters)
  -> @masterpiece/runtime-core Shared Operation Registry (147 operations)
  -> @masterpiece/runtime-core Shared Runtime / service composition
  -> Shared Core packages
```

The 147 operations are the unchanged 136 current business operations plus 11 host-native operations. The Node RPC layer only validates transport, dispatches to the registry, serializes results/errors, and forwards events.

Desktop remains a legacy peer host:

```text
apps/web (shared renderer asset)
  -> Electron preload / IPC
apps/desktop (legacy Electron host + adapters)
  -> same Shared Operation Registry and Shared Runtime
```

Dependency result:

| Boundary | Count |
|---|---:|
| Node Host -> Electron | 0 |
| Node Host -> Desktop | 0 |
| Web Renderer -> Electron | 0 |
| Web Renderer -> Desktop | 0 |
| Shared Runtime -> Electron | 0 |
| Shared Runtime -> Desktop | 0 |
| Operation Registry -> Electron | 0 |
| Operation Registry -> Desktop | 0 |

`apps/web` owns the renderer source. Desktop builds consume that source without the primary Web entry depending on Desktop.
