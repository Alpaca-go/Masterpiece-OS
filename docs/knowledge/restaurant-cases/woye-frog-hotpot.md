状态：**已验收（2026-10-30，条件式）。** 两张图通过，但门口 IP 形象不是用户提供的插画。验收记录：[woye-acceptance-2026-10-30.md](../../evidence/visual-workflow/woye-acceptance-2026-10-30.md)。

## 0. 这张卡最重要的一条

**IP 吉祥物不能用文字描述生成。** 标准空间模式禁止参考图，Prompt 里只有"入口用 3D 化的品牌 IP 装置做视觉焦点"这句描述，外加两条 guardrail（不许抄 mascot、不许发明素材里没有的角色）。三者叠加，模型只能自己造一个青蛙——所以两张通过图里的 IP 都不是用户的插画。

要正确出形象，只有两条路：把吉祥物作为参考图走 `reference_first` / `art_direction_reference`，或者生图后把 IP 像 Logo 一样后期合成。这条已经写进验收记录，属于**产品限制**，不是提示词措辞问题。

> 2026-10-30 补充：已经做出第二条路——项目可以指定「IP / 吉祥物资产」（`select-ip`），并在已生成的图上做**后期合成**（`post-composite-ip`，用的是你自己的插画文件，不经过模型）。代价是贴上去的边缘与光比不会自动融合，属于"形象正确、质感打折"；参考图路线仍未开放（标准空间模式禁止参考图）。

## 3. 设计动作（从两张通过图看）

1. **入口做 3D 吉祥物装置**：吉祥物立在地台或圆盘上，背后是放射状灯带或品牌墙，成为进店第一眼焦点。
2. **紫色做基调、绿橙做分层**：大面积紫色墙面/饰面，绿色出现在灯箱与明档招牌，橙色只做点缀（IP、器皿、局部灯带）。
3. **明档前置**："明档炭锅牛蛙"发光字 + 玻璃后厨，把"现做"放在主视线。
4. **菜单灯箱 + 取餐叫号**：点餐台上方整排灯箱菜单，取餐口另设屏，功能面做得比装饰面更重。
5. **发光线条做节奏**：墙面/顶面的线性灯带（放射、平行）替代图案装饰，制造"IP 世界"的速度感。
6. **模块化桌椅 + 软包**：四人/二人桌混排，织物软包压住紫色的冷感。

## 4. 成立前提（推断）

- 商场允许入口设大型 3D 装置（防火、疏散、结构荷载都要核）。
- 品牌有可用 IP 形象（本项目的形象必须走锁定资产，见第 0 节）。
- 高饱和紫 + 发光字适合年轻客群与夜间；做家庭/儿童定位需要降饱和、加安全圆角。
- 明档需要排烟与补风条件；本项目未提供。

## 5. 禁止 / 误用

- 不要用文字描述去"生成"客户 IP：失败案例已经发生两次（摩托车、头盔蛙、本次 IP 不像）。
- 儿童品牌、家庭客群不要用高饱和紫 + 放射灯带（会被读成夜店/电竞）。
- 没有排烟条件时不要照搬明档前置。
- 不要直接复制"蛙够大 肉才多"标语与吉祥物造型。
