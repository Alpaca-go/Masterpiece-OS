## 0. 项目事实与置信度

*   **品牌名称**：九州美学 (Jiutown Aesthetics)
*   **行业**：医疗美容
*   **核心定位**：精细化、可信赖的高端医美服务，强调科学与美学的结合及温度感。
*   **置信度**：高（基于多张不同触点的高清渲染图/实物图，视觉系统一致性极强）。
*   **关键约束**：主Logo已锁定 (Locked)。

## 1. 关键视觉资产识别

### 1.1 Logo / Locked Asset
*   **图形标 (Symbol)**：
    *   形态：一个抽象的“S”形曲线，结合了凤凰/孔雀的颈部线条与羽毛的流动感。线条流畅，具有动态美。
    *   应用：在所有物料中均作为核心识别点出现。
*   **字标 (Logotype)**：
    *   中文：“九州美学”。字体风格优雅、纤细，接近宋体或定制细黑体，体现精致感。
    *   英文：“Jiutown Aesthetics”。无衬线字体，字号较小，位于中文下方，作为辅助说明。
*   **组合形式**：
    *   标准组合：图形在上，中文在下，英文在中文下方（如 C02-04, C02-19）。
    *   横式组合：图形在左，文字在右（如 C02-12 伞面，C02-26 手提袋）。

### 1.2 辅助图形与纹样 (Auxiliary Graphics)
*   **核心元素：翎羽 (Feathers)**
    *   **视觉表现**：高度写意且带有光泽感的羽毛。
    *   **色彩表现**：呈现出蓝紫色到银白色的渐变，带有镭射或珠光质感（Iridescent/Holographic），暗示“科学与美学”的结合（科技感+自然美）。
    *   **应用位置**：手提袋底部（C02-04）、纸杯底部（C02-19）、信封顶部（C02-28）、背景装饰（C02-13）。
*   **辅助纹样：波浪线**
    *   出现在伞柄套上（C02-12），细密的粉色/紫色波浪线，增加触感细节。

### 1.3 品牌文案 (Copywriting)
*   **Slogan/核心文案**：“精琢 每一片 翎羽”。
    *   排版：字间距较宽，体现呼吸感和高端调性。
    *   含义：呼应品牌名中的“美学”以及图形中的“羽毛”，暗示对细节的极致追求（精细化）。

## 2. 视觉系统提取

### 2.1 颜色系统 (Color Palette)
*   **主色：九州紫 (Jiutown Purple)**
    *   一种高饱和度、略带蓝调的紫色。既代表尊贵、神秘，又符合女性审美。
    *   应用：大面积背景（C02-04, C02-12）、Logo反白（C02-04）、丝带（C02-26）。
*   **辅助色**：
    *   **纯白 (Pure White)**：用于礼盒、纸杯、手提袋底色，提供医疗行业必需的洁净感和专业感（C02-19, C02-26, C02-28）。
    *   **香槟金/金属色 (Champagne Gold)**：用于手拿包（C02-13），提升奢华感。
    *   **深邃黑 (Deep Black)**：用于皮质手提包（C02-21），提供稳重、专业的对比。
*   **特效色**：
    *   **全息/镭射银蓝**：用于羽毛图案的高光部分，增加未来感和科技感。

### 2.2 字体排印 (Typography)
*   **中文字体**：宋体变体或极细黑体。笔画纤细，衬线（如果有）不明显，强调现代东方的精致感。
*   **英文字体**：干净的无衬线体（Sans-serif），字重较轻（Light/Regular）。
*   **排版原则**：
    *   **留白**：大量留白，Logo通常居中或处于视觉黄金分割点。
    *   **对齐**：严谨的对齐方式，体现“精细化”。

### 2.3 材质与工艺 (Materials & Finishes)
*   **纸张**：哑光触感纸（Matte finish），显得高级不反光（C02-04, C02-26）。
*   **织物**：
    *   **缎面丝带**：紫色宽丝带，增加礼品的仪式感和温度感（C02-26）。
    *   **伞布**：高密度碰击布，呈现哑光紫色质感（C02-12）。
*   **皮革**：
    *   光滑的黑色皮革（C02-21）。
    *   带有纹理的金色皮革（C02-13）。
*   **工艺推测**：
    *   **烫银/烫白**：Logo在深色背景上（C02-04, C02-21）。
    *   **压印 (Embossing/Debossing)**：Logo在金色包上似乎是压印效果（C02-13）。
    *   **UV/局部光油**：羽毛图案可能有局部UV，增加光泽度。

### 2.4 跨触点一致性 (Consistency)
*   **高度统一**：无论是纸杯、雨伞、手提袋还是信封，都严格遵循“紫色+白色+羽毛元素”的组合。
*   **灵活变体**：
    *   **白底紫标**：用于白色礼盒、白色纸杯、白色信封（C02-19左, C02-26, C02-28）。
    *   **紫底白标**：用于紫色手提袋、紫色纸杯、紫色卡片（C02-04, C02-19右, C02-28）。
    *   **黑/金底银标**：用于周边礼品（C02-13, C02-21），适应不同材质的高级感。

## 3. 设计决策与建议

### 3.1 Reference First (参考优先)
*   **核心参考**：C02-04（紫色手提袋）和 C02-26（白色礼盒套装）。这两张图最完整地展示了品牌的主色调、Logo应用和辅助图形（羽毛）。
*   **风格关键词**：Elegant (优雅), Ethereal (空灵/羽毛感), Premium (高端), Clinical yet Warm (医疗但温暖 - 通过丝带和羽毛体现)。

### 3.2 Space (空间与陈列)
*   **空间氛围**：建议线下空间使用大面积白色或浅灰色作为基底，配合紫色的软装（如窗帘、沙发）和金属质感的装置。
*   **灯光**：需要柔和的暖光来中和紫色的冷感，体现“温度感”。羽毛元素可以作为墙面的浮雕或灯光投影。

### 3.3 Packaging (包装规范)
*   **礼品感**：包装不仅仅是容器，更是礼遇。必须强调开箱体验（如 C02-26 的丝带设计）。
*   **层级**：
    *   **一级包装**（对外展示）：紫色手提袋或白色礼盒，强调品牌识别。
    *   **二级包装**（内部）：建议使用带有羽毛纹理的硫酸纸或特种纸包裹产品。
*   **周边延伸**：雨伞（C02-12）和手拿包（C02-13, C02-21）是非常好的VIP赠品方向，材质必须考究。

## 4. 限制与不确定性

*   **色值确认**：图片中的紫色在不同材质（纸张、布料、屏幕）上有色差。需要确认标准的 Pantone 色号（可能是 Pantone 268 C 或类似的蓝紫色）。
*   **“DIE 48”含义**：在 C02-04 中出现了一个黑色卡片写着“DIE 48”。这可能是特定产品系列、活动代码或设计师签名。在没有更多上下文的情况下，不应将其视为通用品牌资产，但需留意其排版风格（金色细字体）。
*   **羽毛的具体形态**：羽毛是实拍图还是3D渲染？如果是3D渲染，需要确保渲染风格的一致性（光泽度、羽枝的细节）。
*   **字体授权**：需确认“九州美学”中文字体是否为定制设计或购买版权的商用字体。
