## 设计动作

1. **门头做“白底橙字”整幅灯箱 + 深灰包边**：品牌名与英文并排，左右两端挂副信息（加盟热线 / 浓汤牛骨熬制十二小时），把广告位做成门头的一部分。
2. **立面用“落地玻璃 + 白色长条砖 + 木格栅”分区**：玻璃尽量落地，视线直达室内；砖与木只做收边，不做整墙贴面。
3. **入口右侧放立式灯箱海报**：产品大图 + “鲜虾”等当季卖点，替代灯箱字。
4. **室内主墙做整幅白色立体大字**：把“冒菜配骨汤 / 泡饭就是香”直接做在浅木竖纹墙上，字是空间里唯一的“装饰”。
5. **顶棚裸露 + 圆盘吊灯**：不吊顶，管线外露刷深色；吊灯低垂到桌面以上，靠灯罩聚光而不是整体照度。
6. **家具用“长条高桌 + 橙面木凳”**：桌是浅木框 + 白色台面（台面边缘有印刷图案），凳是橙面 + 木框 + 黑色金属腿，桌下单侧留空便于并排坐。
7. **地面做“水磨石 + 木地板”拼接**：座位区木地板、通道水磨石，用材质分动静线。
8. **物料用漫画 IP 铺满**：牛魔王插画、红底“生人勿近/科研重地”海报、桌贴号码、外卖袋、围裙、扇子；同一套 IP 从门头贯穿到外带。

## 成立前提（均为推断）

- 冒菜是高频、单人份、可外带的品类，才适合“长条高桌 + 少服务 + 快翻台”。
- 门面宽、临街、可做落地玻璃；进深不足时，长条桌会挤掉通道。
- 城市管理允许门头整幅灯箱与立式灯箱外摆；否则副信息要移到店内。
- 品牌有卡通 IP 的版权与延展能力，才能把插画铺满物料；没有 IP 时这套会显得吵。
- 橙色 + 白 + 深灰的高对比配色适合重口味快餐；做清淡品类需要降饱和。

## 禁止 / 误用

- 需要久坐、商务、家庭聚餐的场景不要用长条高桌 + 橙凳 + 裸露天棚，会显吵、显挤。
- 门面窄、玻璃面不足时不要硬做整幅灯箱 + 落地玻璃，会显得空、夜里像广告牌。
- 没有稳定 IP 与物料供应链时，不要铺满插画与海报，容易变成“贴纸店”。
- 浅木竖纹墙 + 白色大字在油烟环境下易发黄；明火/重油烟品类要先解决排烟再谈白墙。
- 不要直接复制“牛魔王”插画、白底橙字灯箱版式与“泡饭就是香”文案。
