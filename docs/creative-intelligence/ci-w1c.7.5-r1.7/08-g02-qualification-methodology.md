# G02 Qualification Methodology

This is a design contract for a future independent qualification. It contains no project-specific claim identifiers, source identity, expected prose, selected file, or live authorization.

## Preconditions

1. A separately authorized phase selects exactly one source under the source-selection contract.
2. The source identity and boundary pass deterministic checks.
3. A human reviewer approves an independent anchor map.
4. `requestTimeoutMs` values are recalibrated offline; no Strategic duration is inherited automatically.
5. A dedicated final gate explicitly authorizes live execution.

## Recommended scope

Use `stopAfter=synthesis` initially to test Planning-to-Strategic generalization. Concept and Direction remain `NOT_RUN`; image calls remain zero.

## Future hard gates

- source identity PASS;
- Planning semantic qualification PASS;
- all applicable G02-specific material anchors retained;
- deterministic epistemic authority PASS;
- canonical accepted Strategic artifact present;
- SG-01/11/12/13/14/15 PASS;
- exact four-domain source-authority mirror PASS;
- material Planning-to-Strategic retention PASS with no silent material loss or contradiction;
- stage-scoped Human Review PASS;
- Strategic-only scope PASS;
- zero image calls and zero unrelated source reads.

Claim count, full citation percentage, direct anchor-reference percentage, unique citation count, and total reference occurrences remain diagnostics. They are not hard gates unless a later explicit methodology review changes the contract.

## Evidence

Use the current qualification evidence architecture and Provider call ledger methodology. G02-specific evidence must remain separate from the frozen G01 manifest. A failed or incomplete run cannot rewrite G01 history.
