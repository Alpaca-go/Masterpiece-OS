## 02｜P0：建立能够被辨识的建筑艺术特征（最高优先）

### 必须正向表达

- 艺术性来自**与建筑相连接的局部珠光半透明曲面系统**，而不是普通的无色玻璃隔断，也不是独立艺术雕塑。
- 在主厅的一个明确区域设置**一组有起止、有方向、有层间节奏的轻薄弧形界面**；可沿侧向建筑界面局部延伸至上部，但**只作用于局部区域，顶面与墙体的大部分仍完整可读**。
- 曲面要有**薄边、错层、深度、轻微珠光内反射**；形成品牌特征与艺术体验，同时参与候客或咨询边界。
- 远近层次必须精细而不密集：具有可读的完整主曲面、少量辅助薄层和可见的结构留白；不可只剩单块普通落地玻璃。
- 珠光局部弱紫仅存在于材料内层；整体仍是暖白/米白，与浅暖木纹形成受控对比。

### 明确禁止回退

- 巨型羽毛/花束/涡旋薄片横扫顶面、密集重复薄片堆叠、双侧近景夹击。
- 将半透明装置扩大为整个大厅的主体，遮挡前台、通行或专业服务区。
- 把艺术系统全部删掉，退化为弧形玻璃屏风、木格栅墙和普通暖色商装。

**检查重点：** 最终 Prompt 必须说清楚“艺术结构在哪里、如何与建筑相连、如何参与分隔、为什么具有珠光特征”，不能仅写“有美术馆气质”“一两处曲面”这类空泛描述。艺术结构的真实形状和占比不需要伪造尺寸或硬性数值。

## 03｜P1：把茶室式洽谈区改成真正的医美咨询服务节点

### 目标场景

完整主厅中同时可辨：**正式接待前台、成组候客、主厅边缘或邻接处的半开放专业咨询节点、通往私密服务区的受屏蔽转场**。功能来自设施和关系，而不是大面积品牌文字。

### 专业咨询节点（关键新增）

- 后方原本“圆桌+木椅”的普通茶室式洽谈场景，调整为**一处皮肤/美学咨询工作位**，建议包含一台简洁的**皮肤影像分析或咨询显示设备**，与专业咨询台面及顾客就坐位置组成明确的面对面服务关系。
- 显示设备可呈现抽象、非可识别个人的皮肤分析可视化界面或简洁影像布局，但**禁止编造诊断文字、指标、病历、治疗承诺或客户个人信息**；禁止生成可读随机字样。
- 可选一处小型内嵌式护肤产品/材料展示龛，**最多一处、少量样品**；若画面承载不了，优先保留专业咨询设备与服务关系，舍弃展示龛。
- 通过通透或半通透建筑边界，访客可以感知专业咨询区存在；专业治疗活动、护理床和私密治疗室不在主厅画面中展示。

### 主厅其他功能

- 正式前台必须清楚看到来访服务面与员工工作位置，可有少量办公设备，**不能只是一件造型家具**。
- 候客区使用成组沙发、扶手椅、轻桌；能坐、能等候、能绕行，**不能变成临窗茶席主景**。
- 后续服务动线可读但不出现一排诊室门或狭长走廊；可以用错位实体界面保护隐私。
- 允许没有人物，仍应凭功能设施读懂空间。准确 Logo 与导视后期处理，不能指望它们单独提供医美身份。

## 04｜P2：恢复艺术性与专业感的材质、光线平衡

- 建筑基底：暖白、米白、少量暖灰；局部自然浅木作为辅助，不让木格栅和木家具主导整个画面。
- 珠光系统：透光、微弱珍珠母贝虹彩和精致边缘，**紫色仅作为局部内反射**，不能做紫色舞台灯或满墙发光。
- 自然光：明亮而温暖、柔和漫射，层次清晰；保留结构阴影与真实材料质感，不能过曝洗白。
- 视觉效果应是“拥有美术馆气质的专业医美商业空间”，而非茶室、SPA 会所、酒店大堂、医院候诊室或纯艺术展厅。
- 不使用随意增加的医生、设备数量、治疗器械或医疗行为来强行证明行业身份。公共接待厅不应变成治疗场景。

## 05｜P3：约束这轮修改范围与实际执行方式

1. **只做最小必要的项目级字段修正**。优先核查：`spatialConcept`、`structureLanguage`、`artisticFocus`、`functionalProgram`、`functionalNetwork`、`functionalRelationships`、`visibleRequirements`、`compositionRequirements`；视实际差异再涉及必要的材料字段。已经正确的暖光字段原则上不变。
2. 先查明最新正式 Prompt 中导致“艺术被弱化、医美变普通洽谈”的**具体正向表达缺口**。不能把单张图的全部随机变化断言为某字段造成；但必须修复文本中可确认的不足。
3. **正向替换优先于负面禁词堆砌**。不要在旧版 11k 字符 Prompt 尾部无穷叠加新句；在其来源字段处删改旧描述，让项目的艺术与专业服务得到明确正向位置。
4. 若通用编译结果仍含 `No artistic installation is required by the supplied sources.` 等泛化语句，先确认其语义是否与项目的**建筑一体化艺术构件**发生实际冲突；不得仅为了消除一句通用文案而擅改生产编译器。无法通过项目级约束解决时，说明阻塞并停止等待授权。
5. 建立新的隔离测试副本，用**正式网页编辑、保存、确认**生效；不能直接写入确认 JSON 或绕过既有业务编译与 Adapter。
6. 做必要的字段保真、Prompt 源映射、零参考图请求预演，以及所属工作流、跨行业回归与仓库门禁；不扩大到与本项目无关的生产改造。

**发生冲突时的优先级：** 可辨专业医美服务功能 + 开阔可信的商业建筑空间 ＞ 与建筑一体化的精致珠光艺术语言 ＞ 暖光与材料平衡 ＞ 零散商业道具。注意不是取消艺术，而是保证艺术不吞没功能。

## 07｜离线验收清单（必须逐项作答）

**艺术性：**
- [ ] 最终 Provider Prompt 明确存在**建筑一体化、局部、精致、有珠光特征的连续曲面**，而不是抽象形容词或普通玻璃隔断。
- [ ] 没有恢复密集羽片/大型涡旋正向机制，前台、候客、顶面与横向视线有足够空间。

**行业属性：**
- [ ] 前台具备接待和员工工作关系。
- [ ] 候客是能使用的成组空间，不是茶室式主景。
- [ ] 半开放服务区至少有**一处与医美咨询直接相关的可辨设备/工作关系**，而不只是四椅圆桌。
- [ ] 该节点不泄露真实客户资料，不虚构医疗结果，不在主厅展示治疗活动。

**美学与工程：**
- [ ] 暖白/米白、局部浅木、柔和暖光与弱紫珠光均在正式/Provider Prompt 中可追溯，未出现冷白过曝新导向。
- [ ] 实际预演为 Seedream 5.0 Pro、2K、16:9、单张、standard、0 参考图、无 `image` 字段。
- [ ] 旧项目、图片、人工验收、Golden 和跨行业请求未变；任何失败均报告，不擅自放宽测试。
