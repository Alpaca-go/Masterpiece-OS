# Explicit ordinary spatial layouts

The spatial source gate rejected a completed restaurant analysis whose structural
language was “开放式” and “明档”. Both were classified as functional prose, leaving
architectureStrategy and architectureForm empty despite explicit layout evidence.
Changing the requested scene could not repair this project-level source failure.

The fix recognizes a bounded set of complete ordinary layout statements only in
`mediaTranslations.spatial.structureLanguage`. Classification, normalization and
action detection share the same predicate. Compiled strategy/form/organization
retain the exact source text and its provenance; they introduce no geometry,
dimensions, materials, operational relationships or user confirmation. Negated,
marketing, decorative and risk prose cannot enter through this path. Truly absent
architecture still fails the existing source gate.

Changes are restricted to the independent workflow's semantic classifier,
normalizer and action detector, their explicitly scoped integrity hashes, tests
and this report. No shared planning/migration implementation, Pipeline, Prompt,
Provider configuration or Adapter changes. No Golden updates or image-quality
acceptance claims.
