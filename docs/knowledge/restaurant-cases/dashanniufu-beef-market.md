## 设计动作

1. **一套符号系统对应四句话**：牛形线条 = 品质好牛/探索家，音符 = 舞动味蕾，心形 = 暖心服务，笑脸/多元 = 天然烹饪家；四种符号同笔触、同橙色。
2. **橙色做品牌主色，白/深棕做底**：门头、包装、制服、标签统一橙色；米白做留白，深棕做质感层。
3. **门头做“橙色大框 + 白字”**：整块橙色檐口包住门面，白色字标“大山牛夫 / LUCK BEEF”直接压在橙面上，夜间用灯箱。
4. **室内用“白墙 + 浅木 + 明档玻璃”**：操作区用玻璃隔出，台面浅灰/不锈钢，墙上只放符号与一句话，不做装饰画。
5. **零售区做冷柜 + 生鲜包装**：牛肉按部位分装，包装用牛皮纸/白色托盘 + 橙色标签（部位、重量、价格）。
6. **外送/社区直达独立成线**：外送箱、封签、手提袋与门店物料同色同符号。
7. **标签系统承担“信息密度”**：部位名、产地、烹饪建议做成小标签阵列，靠排版而不是靠图案。

## 成立前提（均为推断）

- 有稳定的牛肉供应链与分级能力；“品质/产地”叙事必须有真实货源，否则符号撑不住。
- 社区店需要同时做零售与出餐，明档与冷柜的动线要分开，否则排队会互相堵。
- 橙色大面积使用适合“热闹、平价、家庭”；做高端牛肉专营店需要降低面积或改深色。
- 符号系统要能延展到包装、制服、外送、标签；没有物料预算时，四符号会退化成贴纸。

## 禁止 / 误用

- 没有生鲜/零售能力时，不要照搬“冷柜 + 明档 + 多元烹饪”的组合，会变成四不像。
- 高端和牛/精品肉铺不要用大面积橙色 + 卡通符号，会掉价。
- 明档玻璃 + 浅色台面在高油污环境下维护成本高；没有清洁制度不要用。
- 符号系统不是 logo 堆叠：四个符号必须有固定含义与固定用法，否则会互相打架。
- 不要直接复制“大山牛夫 / LUCK BEEF”字标、四个符号的造型与牧场文案。
