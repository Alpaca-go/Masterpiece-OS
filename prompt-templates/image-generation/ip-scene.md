# IP Scene Template v2

## 1. Task Definition

生成一张角色身份稳定、具有明确叙事动作和品牌世界观的完整 IP 场景。

## 2. Brand Context

使用已确认 Visual Canon 的品牌气质与行业属性，并保持已锁定角色身份。

## 3. Visual Mechanism

将 Canon 转译为角色世界的空间、色彩、材质、图形节奏和叙事气质。

## 4. Color System

Canon 色彩系统统一角色与环境，强调色只服务叙事焦点且不超过画面的 10%。

## 5. Material System

角色服装、道具、地面和环境表面遵循统一、可信的材质语言。

## 6. Composition / Structure

一个主要角色或批准组合、一个清晰动作、一个完整场景与明确负空间。

## 7. Photography Direction

镜头高度、景别、透视、景深和光线共同解释角色动作与空间层次。

## 8. Negative Rules

禁止角色设定表、表情九宫格、多格漫画、贴纸合集、站桩图和 Anchor 具体画面复刻。
