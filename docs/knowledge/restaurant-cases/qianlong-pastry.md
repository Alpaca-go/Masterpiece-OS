## 设计动作

1. **门头做"木檐 + 匾额字"**：整幅木色檐口压顶，白色宋体字标居中，左右角标"手工现做/眼见为实"，形成旧时铺面的比例。
2. **两侧留红砖与粗石墙**：不用整墙木饰面，靠砖、石、木三种质感并置，把"老铺"做在材料上而不是贴图上。
3. **室内做整面木格架 + 手绘插画墙**：格架上层放礼盒与产品，下层是木柜；插画墙画江南街市与制饼过程，作为唯一的"故事面"。
4. **柜台用浅石纹 + 木台面**：收银与包装台做成一体，台面浅、柜体木色，避免不锈钢出现在主视线。
5. **印章系统贯穿包装**：红方印"乾隆酥院"作为主图形，出现于礼盒、牛皮纸袋、贴纸、封签。
6. **产品摄影用"剖面 + 流心"**：酥点切开展示内馅，配米白/暖橙背景，作为海报与灯箱主图。
7. **礼盒做两档**：橙色硬盒（送礼）+ 牛皮纸袋（日常），同一套印章与字体。

## 成立前提（均为推断）

- 商场允许木檐外挑与砖石贴面；消防对木饰面与灯带有要求。
- 品类是"送礼 + 自吃"双场景，才需要两档包装。
- 有稳定的产品摄影与插画供给（每季上新品都要换插画）。
- 门面窄但层高足够做匾额与檐口；层高不足时这套比例会塌。

## 禁止 / 误用

- 现代烘焙、日式面包店不要用"匾额 + 印章 + 红砖"这套，会显土、显旧。
- 商场统一门头规范下不要硬做外挑木檐。
- 印章与插画不能替代产品力：产品摄影弱时，这套视觉会显得空。
- 不要直接复制"乾隆酥院"字标、印章、江南插画与"手工现做"文案。
