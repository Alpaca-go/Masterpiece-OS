## 2. 视觉系统提取
### 2.1 颜色系统
- **主色**：高饱和度正红色，为品牌核心识别色，用于背景、主标题、图形Logo、印章元素，传递川味餐饮的热闹感与醒目度。
- **基础色**：黑色、白色，作为文字、背景的基础搭配，红+黑+白为核心色彩组合，保证强对比识别性。
- **辅助色**：棕褐色（用于印章、食材场景自然色调），菜品自然色（牛肉棕、香菜绿、汤汁浅黄）作为视觉内容补充。
- **应用规则**：红底白字/白底红字为最高频的强对比组合，用于品牌名、主标题；深色（黑/深灰）作为食物摄影背景，突出菜品热气与食欲感。

### 2.2 字体系统
- **品牌中文主字体**：「冯烫烫」为厚重创意书法体，笔画粗壮有力，兼具烟火气与识别性。
- **品类/标题字体**：「跷脚牛肉」（圆形框内）为偏传统的宋体风格；传播标题（如「川菜巧搭配 下饭好滋味」）为粗书法体，力量感强，契合街食亲民属性。
- **品牌英文字体**：FENG TANG TANG、QIAOJIAO BEEF均为全大写超粗无衬线字体，字形方正现代，平衡中文的传统感。
- **辅助文字字体**：slogan、说明文字为常规无衬线体，保证可读性。
- **装饰性字体用法**：QIAOJIAO BEEF常以空心线稿形式作为背景底纹，增加版面层次感，不干扰主信息传递。

### 2.3 构图系统
#### 典型版式规则
1. **横版海报**：左右分栏结构，一侧放品牌文字信息，另一侧放核心菜品大图；版面点缀「川菜小馆」印章、背景线稿英文，底部放置全信息Logo组合，信息分区清晰，产品视觉占比30%-50%。
2. **竖版海报/灯箱**：上下结构，顶部放英文品牌名/传播主标题，中部为核心菜品摄影图（占版面60%以上，叠加空心线稿QIAOJIAO BEEF装饰），底部为红色色块+图形Logo+全信息Logo组合，重心在菜品，品牌区稳定醒目。
3. **通用原则**：品牌Logo/名称始终固定在版面顶部或底部；菜品图永远为视觉重心；用红白色块划分信息区，逻辑清晰。

### 2.4 载体与材料表现
- **灯笼载体**：长形中式纸灯笼，分红底白字、黑底白字两款，表面有瓦楞纸肌理，上下带封盖，适合门店氛围营造，兼具传统烟火气与品牌识别度。
- **灯箱/海报载体**：适配户外/商圈墙面，以摄影+平面设计结合的画面为主，醒目度高，信息传递直接。
- **整体风格**：融合传统中式元素（印章、灯笼、书法字）与现代平面设计手法（粗无衬线英文、大块面色彩、线稿装饰），契合「现代街食品牌」定位。

### 2.5 跨触点一致性
- 核心元素统一：品牌Logo组合、「冯」字图形标、红黑白主色、核心slogan、背景线稿字在横版海报、竖版海报、灯笼、灯箱所有触点中统一复用，识别度高。
- 风格统一：所有触点均保持「传统川味+现代街食」的平衡感，既有餐饮烟火气，又有现代品牌的整洁感。
- 信息层级统一：「品牌名→产品/传播标题→slogan→辅助信息」的层级逻辑在所有载体上保持一致，信息传递效率统一。

## 3. 设计决策与建议
### 3.1 Reference First 参考复用建议
可直接复用的标准化资产库（需严格遵循锁定规则）：
1. **Logo资产包**：全信息主Logo锁版、「冯」字图形Logo、「川菜小馆」辅助印章，所有物料不得修改形态、比例、配色。
2. **色彩规范**：正红+黑+白主色体系，红底白字/白底红字的强对比应用规则，可直接延伸至所有品牌物料。
3. **字体规范**：中文书法粗体+英文超粗无衬线体的搭配规则，以及空心线稿英文背景字的装饰手法，作为统一视觉语言复用。
4. **内容资产**：两款核心跷脚牛肉产品图、3套固定slogan，可根据场景（定位宣传/地域背书/消费引导）选择使用。
5. **版式模板**：横版、竖版海报的标准化构图，可直接替换文字/局部素材产出新物料，保证品牌一致性。

### 3.2 Space 空间视觉建议
- **门头店招**：优先使用红底白字主品牌名+图形Logo的组合，搭配长形红灯笼作为氛围点缀；可加入「川菜小馆」印章与「跷脚牛肉」品类名，快速传递品类信息，保证街面远距离识别性。
- **店堂内部**：墙面海报沿用现有竖版/横版版式，以菜品图+品牌信息为主，强化食欲感；可红黑两款灯笼搭配布置软装，增强传统街食氛围。
- **商圈/户外灯箱**：沿用「大尺寸菜品图+醒目标题+底部品牌红块」的设计逻辑；不同位置灯箱可搭配不同slogan，分别传递地域背书、产品价值、消费场景等多元信息。

### 3.3 Packaging 包装视觉建议
（基于现有视觉系统的延伸建议，需后续结合落地需求验证）
- **外卖打包袋/盒**：主面使用红底白字的「冯烫烫」主品牌名+「跷脚牛肉」品类名+「冯」字图形Logo，侧面加小号定位slogan，醒目且传递品牌价值。
- **堂食餐具**：参考主视觉的蓝边碗、土陶砂锅风格，选用偏传统的粗陶/蓝边餐具，契合川味传统属性。
- **耗材类（餐巾纸、小票等）**：使用白底红字的简约设计，印小型Logo组合，控制成本的同时保持品牌一致性；可加入空心线稿QIAOJIAO BEEF作为暗纹，增加细节感。
