# G02 Independent Anchor-Map Contract

Every future G02 live qualification requires an independent, human-reviewed anchor map created from the separately authorized G02 source. The recommended schema identifier is `ci-qualification-anchor-map-v1`.

Each applicable entry must include:

- anchor ID or key;
- exact source section reference;
- semantic expectation;
- materiality;
- applicability;
- reviewer note.

The map must explain omissions and non-applicable concepts, preserve requirement modality, and distinguish source propositions from reviewer expectations. It must be reviewed before qualification thresholds are evaluated.

G01's 12 keys are project-specific evidence. They must not be copied mechanically, treated as a universal taxonomy, or used to pre-shape G02. Shared architecture and methodology may be inherited; project semantics may not.

R1.7 creates no G02 anchor-map instance and authorizes no G02 source read.
