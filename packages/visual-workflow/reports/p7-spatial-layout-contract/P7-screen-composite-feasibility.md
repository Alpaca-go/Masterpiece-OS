# P7 咨询屏幕后期替换：只读审查与提案

结论：**部分支持基础合成；不支持现成可配置的精确咨询屏幕局部替换工作流**。本轮未实施后期、未创建图像素材、未增加付费调用。

[现有Logo合成实现](../../src/runtime/image-generation/logo-post-composite.js) 第61–102行支持源图矩形裁剪、可选去底、按宽度等比缩放及x/y定位，以sharp.composite输出PNG并记录摘要。它可以在不重新生成主场景的条件下贴合平面图层，是可借鉴的基础能力。

[业务入口](../../src/runtime/image-generation/short-chain-service.js) 第962–1013行要求confirmedByUser、成功run、项目素材、post_composite模式；界面调用位于[独立工作流网页](../../../../apps/web/src/features/visual-workflow/VisualWorkflowWorkspace.tsx) 第136行，面向Logo裁剪和位置，未提供咨询屏幕四角、目标区域mask、透视、反光、遮挡保护或屏幕内容审批参数。不能把Logo入口改名或挪用素材就宣称支持精确屏幕替换。

最小可行提案（未来独立审核，当前未开发）：先由人工批准场景布局与屏幕有效像素；人工标出内屏四角及边框/遮挡mask，选定经审核的非个人皮肤比例设计素材；离线透视投影至内屏，保护边框与前景遮挡，保留合理亮度/反射；仅输出新派生图并记录原图/素材/mask/变换/结果摘要。对目标mask外像素做差异检查，对边缘、透视、可读性做人工复核。

工程需要独立的屏幕区域与审批数据契约、透视变换及mask实现、界面确认和测试；不能通过本轮项目字段补出此能力。不调用模型也不能修正错误座位或主厅几何。若屏幕过小、被遮挡、曲面严重或布局不合格，应停止合成并回到人工评审，不能用错误画面掩盖拓扑问题。
