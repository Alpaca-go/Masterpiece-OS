## 续2：修复运行期报错 colorRulesAreFlexible 并重新打包
用户反馈运行「参考风格重构」时报 `核心视觉方向不可执行：colorRulesAreFlexible`（失败步骤 GENERATION_DIRECTION）。

### 根因
`reference-style-reconstruction.ts` 两路径不一致：
- `validateReferenceStyleReconstruction`（质量校验，~L1398）：当 `referenceFirstStrategy` 存在时强制 `visualDirectionIsExecutable=true`（软放过）。
- `finalizeReferenceStyleReconstruction`（落盘最终化，~L1421）：**无条件**调用 `validateVisualDirectionExecutability`，要求 LLM 生成方向里 `flexibleColorSystem`（identityColorRole / backgroundOptions / touchpointVariations≥2）字段齐全，否则抛 `VISUAL_DIRECTION_NOT_EXECUTABLE`。模型输出常不保证这些字段，于是 finalize 在 `enforceReferenceFirstDirection` 执行前就硬抛，整个 pipeline 失败。

### 修复
将 `finalizeReferenceStyleReconstruction` 内的 `validateVisualDirectionExecutability` 调用改为 try/catch 软失败（注释说明：reference-first 流程已由 `enforceReferenceFirstDirection` / Generation Readiness Gate 接管执行性校验，最终质量校验对 reference-first 会强制 pass）。质量路径不变，pipeline 层直接 throw 的测试（tests/reference-translation-service.test.ts L494 模拟 LLM 抛错）不受影响。
