## 设计动作

1. **门头整面铺红色小方砖**，中央嵌黑底金边大匾：白字品牌 + 红色“牛|杂|煲” + 英文；下沿木格栅坡檐和“干净用好料”横匾。
2. **左侧临街开大窗做明档**：窗内白色瓷砖 + 不锈钢台，上方并排数字菜单屏；把操作现场直接暴露给街道。
3. **右侧玻璃门/落地玻璃**，门扇贴白色手写体短句，保持内外视线；灰色砖柱把立面分格，形成老街铺的节奏。
4. **室内主墙灰色砖 + 金色立体字“坊间老手艺”**，顶部红色灯槽勾边；红门/红吊旗重复红色，形成强记忆。
5. **用餐区绿色小方砖矮墙 + 镂空花格砖**，分隔卡座/桌区但保持通透；沿墙做红色长卡座。
6. **右侧整墙木格“牛部位图鉴”**：小木牌写部位名 + 线描图，顶天立地，成为知识型背景墙。
7. **裸顶下加木构坡屋顶/椽条**，挂红色布幔/吊旗，形成“坊间棚子”的包裹感；黑色裸顶保留设备。
8. **家具浅木色桌 + 灰布椅 + 红色长卡座**；桌面白瓷碗/砂锅，物料用红绿票券、搪瓷杯、印章，统一市井语气。

## 成立前提（均为推断）

- 门头宽、层高足够，才能做厚匾 + 木格栅坡檐 + 室内坡屋顶三重元素而不压。
- 商场/街区允许高饱和红色外立面、明档/明火/排烟；否则临街开窗不成立。
- 进深足够容纳明档、前场、后厨、卫生间；图内有卫生间门，说明后场序列存在。
- 10:00–22:00 全时段经营，门头/室内照明需兼顾白天与夜晚。
- 顾客对“牛的部位”有兴趣，才值得做整墙图鉴；否则会变成无效装饰。

## 禁止 / 误用

- 层高不足/门头窄时，不要做厚匾 + 木格栅坡檐 + 室内坡屋顶，会压。
- 排烟/明火/商场外立面不允许时，不要做临街明档和整面红砖。
- 品类清淡、高端、商务时，不要用红绿撞色 + 大字书法 + 花格砖，会过重。
- 进深不足时，不要做绿砖矮墙 + 花格砖 + 中央卡座，会切碎动线。
- 不要复制“赵得意”品牌名、匾额字体、印章、牛部位图鉴；只借鉴“红砖门头 + 明档 + 图鉴墙”的方法。
- 若实际是商场店，不要照搬独立街边门头的厚匾/雨棚，可能违反商场立面规范。
