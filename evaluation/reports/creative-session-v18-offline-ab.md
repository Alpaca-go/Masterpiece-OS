# Creative Session v18.1 离线 A/B 验证

验证范围：冯烫烫、九州美学各自的室内空间、包装、海报，共 6 个项目级任务。

本报告只记录不调用真实 Provider 的合同级验证，不声称代表最终图片质量。

| 项目 | 旧流程风险基线 | 新流程离线结果 |
| --- | --- | --- |
| 冯烫烫 | Logo 墙 + VI 展示、旧包装换材质、Logo + 产品照片 | 开放后厨/共享餐桌空间、原纸单色包装系统、真实烟火事件海报 |
| 九州美学 | 表层新中式陈列、Logo 贴附式包装、产品模板海报 | 器物与木作空间、观看距离分级包装、单件器物光影叙事 |

共同验证结果：

- Final Prompt 以用户本次任务为最高优先级，并绑定 Creative Direction ID/版本；
- Provider 参考图不超过 2 张；
- `reading_only` 资产不进入最终参考集；
- 身份参考最多 1 张，必要结构参考最多 1 张；
- Canon 继续提供结构化规则，但不再默认作为图片发送；
- 最近反馈最多继承 5 条，避免无限增长；
- Same Instruction Retry 不重新执行 Reading；
- Session 重启恢复、旧 Run 读取和 Desktop 构建由自动化回归覆盖。

每个任务的离线合同代理评分均满足：品牌准确度、重构程度、分析报告落实、设计完成度 >= 4。
这些分数只证明 Prompt/快照合同，不代表图片质量。

真实 Provider 结果已单独记录于
`evaluation/reports/creative-director-v18.1-real-provider.md`。当前本机只有冯烫烫完整项目，
因此九州美学仅报告离线冻结回归，不冒充真实图片 A/B。
