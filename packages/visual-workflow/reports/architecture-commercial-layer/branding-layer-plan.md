# 九州美学品牌身份分层落地计划

本轮只读审查现有能力，不运行项目 Logo/文字合成，不新增模块，不补造素材。空间图的 `logoUsageMode: post_composite` 只表示身份责任移至后期，不表示准确品牌内容已经具备或完成。

## 三层责任

| 层级 | 当前离线修正可表达的内容 | 不应声称的结果 |
| --- | --- | --- |
| 空间级服务身份 | 到达可见完整前台、可接近服务面、单组候客、单一错位屏蔽服务门槛；即使无人也能理解服务关系 | 仅凭平板或箭头就能证明是医美，或已经完成登记/预约软件 |
| 建筑几何载体 | 前台相邻、平整、清洁、小尺度、未被层片遮挡的无字身份位置；单一门槛界面上的可选小型无字导视位置 | 已锁定真实图的投影平面、精确像素坐标、字标尺寸或自然阴影 |
| 准确品牌内容 | 后续由用户认可的正式 Logo、含正式字标的原图或获批准导视文案承担，使用确实可用的能力 | 从 C 图取字、猜英文翻译、生成标语、虚构正式 Logo，或假定现有系统支持任意文字排版 |

本轮 Provider Prompt 继续禁止模型绘制品牌名、字标、Logo 与导视文字，A/B/C 图全部不进入图像输入。几何载体没有改变这个边界。

## 现有功能：代码审查结论

| 能力 | 实际实现与入口 | 可用范围与局限 |
| --- | --- | --- |

## 当前项目素材和配置缺口

只读审查的源项目为上一轮商业属性真实验证项目。其 `project.assets` 中没有选中的 `role: logo` 资产，因此当前网页条件下不会出现可用的合成按钮。

历史编译计划引用 `visual_decision_packet.lockedAssets` 中的候选 ID `fe40b0b3-22ce-4616-ae5a-8c2370a0791c`；该 ID 在项目中存在，名称为 `九州美学视觉方案-07.png`，状态 ready、类型 image/png，但没有已选 Logo 角色。源 SHA256 为 `fd202e5d923577b78f88b0a0ae887c5bdf8b226dab4579511954f815d3531ced`。没有从名称或 ready 状态推断其中必然有已获批准、可直接使用的 Logo/字标裁切。

因此需要后续独立确认：正式 Logo/字标原文件、精确内容与版本、是否已有透明背景、允许的裁切、批准的品牌文字，以及导视的准确文案。这些不能由本轮七张图片的文字或图案自动代替。

`visual-workflow:select-logo` 当前会同时把分析上下文设为 missing、项目设为 ready。直接在本轮副本重选 Logo 会导致重新分析依赖；本轮未执行该操作、没有改写上下文或假定允许额外模型调用。未来需单独评估素材选择、上下文和确认链的影响，不静默补字段绕过状态约束。

## 导视文字与视觉融合：真实能力缺口

- 没有找到现有独立工作流中的任意文字输入、字体选择、字距/换行、功能牌批量排版或正式导视文案审核入口。
- 没有找到现有合成器中的透视四点映射、曲面投影、遮挡分层、材质/反射/光影拟合及自然落影能力；当前是二维图层叠加。
- 网页目前对整个源 Logo 图使用全图裁切；底层方法有矩形裁切参数，但网页没有交互裁切工具。复杂背景的自动抠图也未得到支持；已有可选移除逻辑仅按角点颜色与阈值处理。
- 未执行当前项目的实际素材合成、准确性检查或视效评估。既有回归中的合成测试使用合成测试素材，只证明原有逻辑，不替代本项目验收。

准确导视文字和自然建筑表面贴合应作为后续独立工作项。不得把新的文字图当作 Logo 偷渡现有入口，也不承诺通过一次二维叠加就能达到自然建筑标识效果。

## 后续可审查的落地顺序（本轮不执行）

1. 用户先审核空间级方案，未来如另行授权真实单图，则仍为 standard 零参考图；没有真实图之前不指定任意像素坐标。
2. 在新图中人工检查前台相邻平整身份面及单一服务门槛的可见性。若被层片遮挡或有随机文字，记录问题，不在本轮自动修图或再生图。
3. 用户确认正式 Logo/字标文件、素材审批状态和位置意图；单独处理当前 Logo 角色与上下文失效的依赖，不改历史项目。
4. 若批准采用现有二维能力，只在用户再次明确确认目标图、素材裁切、位置及比例后，通过既有正式合成入口执行；先将预计效果作为可审查对象，不把它标成已通过。
5. 导视准确文案、字体及透视/光影融合另立范围与验收，不假定已实现。本轮没有授权新增生产模块，也没有自动安排该后续工作。
