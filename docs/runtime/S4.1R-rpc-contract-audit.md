# S4.1R RPC Contract Audit

## Existing transport

| Surface | Contract |
|---|---|
| Health | `GET /_masterpiece/health` -> `{ ok, mode, timestamp }` |
| Operation | `POST /_masterpiece/rpc/:encodedChannel` with `{ args: unknown[] }` |
| Success | HTTP 200 with `{ result }` |
| Failure | HTTP 500 with `{ error: message }` |
| Events | `GET /_masterpiece/events`, Server-Sent Events keyed by operation event channel |
| Origin | Missing Origin or exact configured Renderer origin |
| Request limit | 10 MiB JSON body |

The Renderer maps the existing `DesktopApi` surface to channel names in `web-api.ts`; no secret is included in renderer state or RPC responses.

## Operation coverage at entry

| Class | Count | Owner |
|---|---:|---|
| Business operations | 136 | Shared Operation Registry factories |
| Native host operations | 11 | Electron adapter |
| Total known channels | 147 | One Web RPC surface |

Business families are Settings, Project, Report, Analysis, Project Context, Context Integration, Document, Reference, Image/Space/Packaging, Visual Memory, Creative Session and Creative Production.

## Compatibility decision

- Keep channel strings, positional argument order, JSON request/response shapes and error-message behavior.
- Keep SSE event names: `analysis:progress`, `document-context:progress`, `reference-anchor:progress`, and `image-generation:run-updated`.
- Node RPC code may decode, dispatch and encode only.
- The Shared Operation Registry remains the source of truth; no Web-specific registry or service implementation is allowed.
- Native Desktop channel names remain reserved. Node equivalents are host adapters and are not business operations.

## Existing smoke coverage

The Electron-hosted entry smoke verifies health, renderer load, settings, cancellation, provider capability resolution, Reference First options, compile-route reachability and generation-route reachability with zero Provider calls and zero business writes. The Node-hosted smoke must retain these checks and add zero-Electron/zero-Desktop process evidence.
