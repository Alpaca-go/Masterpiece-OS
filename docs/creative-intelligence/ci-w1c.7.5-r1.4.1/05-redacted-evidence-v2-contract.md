# Redacted Evidence v2 Contract

Schema: `ci-qualification-evidence-v2`.

The export contains only source hashes, a redacted call ledger, Planning IDs/keys/classes/sourceDocumentId/chunkRefs, allowed source sets, artifact mirror sets, blocked codes, stage statuses, per-element planningClaimRefs, used/uncited claim IDs, occurrence counts, direct anchor coverage, and epistemic decision evidence.

Epistemic decision evidence includes model proposal, deterministic class, final class, route, source section references, and modality-marker lists for source windows, extracted values, and evidence summaries.

The validator rejects credential and payload-bearing keys including API keys, credentials, raw text, raw outputs, response bodies, base URLs, and full provider responses. It creates no new source or claim authority.

The reconciled Attempt 3 export is `attempt-3-evidence-v2.reconciled.redacted.json`; it validates and is independently recomputable for claim usage and epistemic decisions.
