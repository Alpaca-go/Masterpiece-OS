## 2. 视觉系统提取（颜色 / 字体 / 构图 / 材料 / 跨触点一致性）

### 🎨 颜色系统
| 角色 | 视觉证据来源 | 描述与建议色阶 |
|:---|:---|:---|
| **基础中性色** | `[Reference-07]` 墙面/地面/天花 | 微水泥灰、暖白、浅原木色。占比约 70-80%，奠定“去医疗化”的静谧基底。 |
| **品牌主色** | `[Reference-09]` 羽毛颈部 & `[Reference-07]` 柜台底光 | 深紫/蓝（Royal Purple / Indigo）。具神秘感与高级感，象征精准与美学升华。建议提取 HEX 范围 `#4A2D6A` ~ `#6B4C9A`。 |
| **点缀色** | `[Reference-09]` 羽毛尾羽高光 | 暖铜/浅橙（Warm Copper）。占比 <5%，用于打破冷调，提升温度感与视觉焦点。 |

### 🔤 字体与排版
- **中文字体**：现代无衬线或极细衬线体（视觉上接近 `PingFang SC Light` / `思源黑体 CN Light`）。字重极轻，强调精致感。
- **英文字体**：几何无衬线（Geometric Sans），字间距（Tracking）显著加宽（约 `150-250`），营造呼吸感与国际高端定位。
- **排版逻辑**：左文右图/非对称留白。文案层级清晰：主标语 > 品牌英文 > 版权/设计方信息。反白显示，确保在深色背景下的可读性。

###  构图与形态
- **空间构图（`[Reference-07]`）**：流线型动线引导。弧形前台、弯曲玻璃隔断、隐藏式灯带天花板，消除直角带来的冰冷感。
- **平面构图（`[Reference-09]`）**：动态对角线构图。飞鸟姿态打破静态平衡，羽毛细节占据视觉重心，文案以网格对齐方式稳定画面。
- **形态语言**：`弧线`（Arc） + `放射`（Radial） + `渐变`（Gradient）。统一指向“柔和、精准、生长”的视觉隐喻。

### 🧱 材料与工艺
- **空间材质**：微水泥（墙面/地面）、磨砂玻璃（带激光蚀刻放射纹）、温润木饰面（墙面护墙板）、织物软包（沙发）。
- **平面/物料潜在工艺**：哑光纸基、局部 UV 凸起（模拟玻璃纹理）、烫印/专色印刷（还原品牌紫与铜色光泽）。
- **光环境**：间接照明为主，无直射强光。紫光仅作为“识别性氛围光”出现，避免医疗焦虑。

###  跨触点一致性
- **色彩一致性**：`[Reference-07]` 的柜台底光与 `[Reference-09]` 的羽毛主色形成强绑定，空间与平面共享同一色相。
- **纹理一致性**：玻璃隔断的放射状纹理与羽毛的结构纹理在视觉节奏上呼应，可抽象为品牌辅助图形库。
- **情绪一致性**：两者均传递“静谧、精准、高定感”，符合“科学+美学+温度”的品牌角色。

## 3. 设计决策与建议（Reference First / Space / Packaging 角度）

###  Reference First（核心视觉策略）
1. **隐喻统一**：以 `[Reference-09]` 的“翎羽/飞鸟”为核心视觉原型。将“精琢每一片翎羽”转化为品牌工艺标准，应用于所有视觉触点（如：疗程命名、会员等级、项目手册插画）。
2. **辅助图形系统**：提取 `[Reference-07]` 玻璃隔断的放射状线条与 `[Reference-09]` 羽毛的渐变层次，生成两套可缩放的 Pattern（用于包装底纹、空间地贴、数字端 Loading 动画）。
3. **Logo 应用规范**：基于约束“原始 Logo Locked”，建议在深色背景（如 `[Reference-09]`）使用反白版，在空间浅色微水泥墙面使用深灰或品牌紫专色版，保持最小安全边距。

### 🏢 Space（空间与体验设计）
1. **Signature Light 应用**：延续 `[Reference-07]` 柜台底光策略，在导视牌底部、VIP 室门缝、走廊踢脚线设置低照度品牌紫光，形成“光之动线”。
2. **材质分级**：公共区（接待/候诊）使用 `[Reference-07]` 的微水泥+木饰面组合，降低距离感；核心操作区采用更高洁净度的哑光白+抗菌材质，通过玻璃隔断实现视觉通透与物理隔离。
3. **声学/嗅觉配合**：建议空间背景音采用白噪音/自然频段，配合木质/柑橘调香氛，强化“温度感”与“去焦虑化”体验。

### 📦 Packaging / Print（物料与触点规划）
1. **色彩配比**：严格遵循 `70% 中性灰/白`（安全/科学） + `20% 品牌紫`（美学/识别） + `10% 暖铜/留白`（温度/呼吸）的配比原则。
2. **工艺建议**：
   - 品牌手册/项目册：选用 120g 哑粉纸，封面局部 UV 压印放射状纹理，标题使用专色紫印刷。
   - 术后护理包：牛皮纸/再生纸盒，内部衬垫使用品牌紫哑光纸，体现环保与精致感。
   - 数字端（App/小程序）：背景使用浅灰微纹理，按钮与关键状态色使用品牌紫，交互动效参考羽毛飘落的缓动曲线（Ease-out）。
3. **排版网格**：延续 `[Reference-09]` 的宽字距与左对齐逻辑。建立 8pt 基准网格系统，确保多语言排版时的视觉稳定性。
