# 后续单张执行门禁方案（本轮不运行）

1. **合法项目先于确认**：只使用用户指定且获准实验的隔离项目，核对已完成分析及 ready 上下文。状态不满足、隔离或来源不清即停止；不能补造分析、替换 projectId、手改状态或写生产项目。
2. **确认先于冻结**：由正式 saveDraft → confirm → capture 绑定已批准的 E0 设计；审计项目 ID、分析指纹、record SHA、confirmation SHA。然后通过正式纯编译冻结 Effective Packet、task、正式与 Provider Prompt，并审阅三方语义差异。
3. **冻结先于新签署**：只有合法确认、正式纯编译成功且来源差异完全解释，才生成 confirmed-executable-freeze.json；由用户人工批准其中的新可执行摘要。旧 E0 或诊断摘要均不能充当该基准。
4. **签署先于调用**：紧贴 dispatch 再从正式服务重编译，以新批准基准逐字节检查 Effective Packet、task、正式与 Provider Prompt、来源、方向记录和全部关键 SHA。来源权威的预期变化只在冻结前解释；冻结后的任何漂移均停止，不自动豁免。
5. **参数与权限门禁**：固定 Seedream 5.0 Pro、standard、dining、three_quarter_wide、user_explicit、16:9、2K、count=1、references=0、Logo/品牌文字 post_composite。检查场景权威、语义、参考图边界与完整性守卫；不放宽规则或手改 payload。
6. **凭据与费用门禁**：仅核对独立工作流的正式已配置凭据归属；不回退全局配置。核实现行计费依据、账户费用记录可得性、实际请求字段及调用范围。费用不明、缺凭据、Provider 状态未知均停止；不得付费探测、换模型或借用其他授权。
7. **单次执行与停止**：仅在前项全部通过且授权仍有效时发出一次生图请求。真实分析、模型校验和自动重试均保持 0；无额外轮次。异常、超时或结果未知立即停止，不因未收到图片而认定未计费。
8. **证据与人工验收**：保存实际 Run、完整实际 Prompt、请求摘要、参数、用量与费用可得性、原始结果图及其 hash；密钥和完整 Provider 原始响应不得提交 Git。结果图在授权的本地运行目录交付。生成完成立即停止，等待人工评图；不更新 Golden、知识验证或视觉质量验收。

历史单张额度尚未使用。本轮不做第 6 项真实账户探测，更不运行第 7 项；该方案也不构成新的费用或模型调用授权。
