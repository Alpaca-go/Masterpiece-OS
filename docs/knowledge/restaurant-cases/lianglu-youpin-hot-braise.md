## 设计动作

1. **门头做“橙框 + 红底白字”双层灯箱**：外圈橙色包边，内框朱红底白字“良卤有品 · 热卤社”；两侧延伸出竖向白底小灯箱做侧招。
2. **吊顶做悬挑木格栅**：橙色结构下方悬吊一排木格栅单元，格栅面写“现捞入味”等短语，既遮结构又做第二层信息面。
3. **前场做明档冷柜 + 不锈钢台面**：冷柜里成品卤味按盘分装，柜前是取餐/收银台；明档不是为了看烹饪，而是为了看“现成的货”。
4. **后墙做木抽屉柜墙**：整面墙做成小抽屉单元，每格贴“卤”印章与品类小字，把“卤味铺的柜”做成装饰面。
5. **白瓷砖墙面 + 橙色大字**：操作区用白色小方砖（易清洁），一面墙刷“包汁热卤 / 现捞 / 入味”大字，字距松、无插图。
6. **电子菜单屏替代贴纸菜单**：两台竖屏/横屏灯箱显示产品照片与价格，随季节换品不用重做墙面。
7. **少量高脚桌 + 橙色高脚凳**：堂食只保留 4 张高脚桌，围绕柜台布置，明确“快吃快走”。
8. **物料统一“橙 + 白 + 卤印章”**：纸碗、打包袋、台卡序号牌、围裙/T 恤、贴纸全部同色系；产品图统一俯拍 + 深色底。

## 成立前提（均为推断）

- 档口面积小、没有独立厨房时，卤味必须在中央厨房预制，门店只做“现捞/复热/分装”，否则明档冷柜放不下工艺。
- 商场或街面允许开放式档口与明火/复热设备；有排烟与消防限制时要改电加热。
- 单品价格带低且统一（图内全 12.00），靠出杯量而不是客单；堂食座位只能是补充。
- 有稳定冷链与中央厨房，才能把“现捞”作为卖点而不是现做。
- 电子屏点单需要门店有稳定供电与网络；否则应保留墙面菜单作为备份。

## 禁止 / 误用

- 正餐、宴请、需要久坐的品类不要用“高脚桌 + 冷柜明档 + 全 12 元”的组合，会把客单和停留时间一起压死。
- 没有中央厨房与冷链时，不要承诺“现捞”；冷柜里摆成品与“现捞”叙事会互相打脸。
- 卤味是高油高色品类，白瓷砖与浅色木格栅的清洁成本高；没有日常擦洗制度不要用大面积白色。
- 橙色 + 朱红 + 全屏产品图在低照度空间会显脏；不要在暗场里做这套配色。
- 不要直接复制“卤”印章、抽屉柜墙的排版与“现捞热卤”文案。
