## 设计动作

1. **门头做“布幔 + 木檐”双层次**：木格栅外挂一段亚麻布幔，布幔上印太阳放射形标志与英文品类；布幔下方藏灯带，把光洗在布面与木檐上，形成“老摊位”的软边界。
2. **立面用青砖与旧木格栅拼贴**：门面一侧是青砖/文化石贴面，另一侧是竖木格栅与玻璃门窗，把“巷子墙”与“店内”并置。
3. **招牌字号做“招牌 + 角标”体系**：主字标“巷子粉铺”配“招牌”小印章角标；另设竖排“巷子有粉铺 / SHUBIAN POWDER SHOP”副牌，形成两块可读的品牌面。
4. **窗台做竹编灯笼阵列**：灯笼是竹编外壳 + 内透光，灯笼面印“粉”等单字，垂在窗洞与室内之间，白天是陈列、夜里是光源。
5. **室内天花板吊布幔印书法**：布幔从顶棚垂到灯笼上方，把“老招牌/老字号”的字感搬到天花，弱化裸露结构。
6. **墙面做旧木刷白 + 朱红大字**：主墙用洗白旧木板做底，朱红手写体“巷子有粉铺”直接上墙，配英文与印章；另一侧墙挂竹编篓/竹筒做立体陈列。
7. **家具统一竹木 + 深色桌面**：竹椅、竹凳、竹编靠背与木桌，桌距紧；靠墙做深棕软包长座，形成“快餐效率 + 老店坐感”的混合。
8. **明档窗口做“菜单灯箱 + 保温柜 + 饮品柜”一条线**：窗口上方是“八小时高汤/招牌高汤 现切牛肉”灯箱，柜内摆瓶装饮品与保温桶，把产品证据放在取餐视线高度。
9. **物料沿用同一套字与色**：打包盒、纸袋、杯、桌贴、立牌、菜单页统一朱红 + 米白 + 牛皮纸；用“六格卖点徽章”（骨汤、现切、鲜、匠心等字样）做重复识别。

## 成立前提（均为推断）

- 门面虽小但门头有足够高度挂布幔与灯笼；布幔下沿不能压到 2.1 米以下，否则通行受阻。
- 街面允许外挂布幔、灯笼与灯带（部分城市对悬挑物、明火光源、招牌照明有审批要求）。
- 品类认知足够强：路人看到“牛肉粉/高汤”就知道卖什么，才敢把品类并置在布幔而不是大灯箱上。
- 店面进深足够放“明档窗口 + 堂食区”；进深不足时，灯笼与布幔会压掉座位区净高。
- 竹木与布幔属于可燃/易污材料，需要可拆洗与阻燃处理；油烟大的厨房动线不能与布幔同侧。

## 禁止 / 误用

- 门头窄、层高低的店不要照搬“布幔 + 灯笼 + 吊布幔天花”三层叠加，会压净高、显压抑。
- 不是“老招牌/手工”叙事、而是干净快取的品类时，不要用旧木刷白 + 朱红手写 + 竹编，会显旧、显脏。
- 排烟、消防不允许明火或明档的铺位，不要把窗口做成开放式出餐口。
- 布幔、竹编、旧木都属于高维护材料；没有日常清洁与更换预算时不要用。
- 不要直接复制太阳放射标志、印章角标、布幔书法文案与“巷子”命名。
