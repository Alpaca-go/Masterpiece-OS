# 未应用的 B* 模板替换

项目材料、照明、经营与风格限制已通过离线候选 Packet 及合法当前任务字段进入正式编译。下列精确文本替换**未进入正式编译**；它们需要修改受保护 space/compiler.js，不能靠人工改 Provider payload 实现。逐项原文、目标文与源码摘要见 [独立差异](unapplied-template-diff.json)。

1. premium-grade → commercial architectural：中性化质量措辞；当前仍保留原正式句。
2. reception / waiting / access / privacy 通用上下文 → 本项目制作、服务、堂食上下文：当前仍保留原句；当前任务另行限定本项目空间，未删除其他合理边界。
3. 可选 gallery-like 等模板句 → 温暖四川社区小馆句：原正式句仍存在，但当前项目任务明确不采用画廊式整体视觉。无法保证模型会优先遵循哪处语境，需人工接受该剩余风险或另行审批模板修订。

High-end architectural visualization / photoreal / physically based materials 属渲染质量语境，保留；no generic AI clinic look 为负向防污染规则，保留。

本轮没有输出拼接后的新 B* 并声称其为 Compiler 结果，也没有为 B* 生成 Provider 请求。独立差异仅为今后审批材料。半通透格栅、射灯及反射数值、精确尺寸和开窗位置没有进入候选，原因是缺少项目确认与物业证据；不作为事实补齐。
