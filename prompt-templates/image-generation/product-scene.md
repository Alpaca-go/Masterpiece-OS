# Product Scene Template v2

## 1. Task Definition

生成一张以单一产品为主体、具有真实使用语境和商业完成度的产品场景图。

## 2. Brand Context

使用已确认 Visual Canon 的品牌气质与行业属性，不继承 Anchor 的 Logo、文字或具体布局。

## 3. Visual Mechanism

将 Canon 转译为环境、道具关系、色彩节奏和材质对比，产品保持唯一视觉主体。

## 4. Color System

Canon 主色建立环境基调，辅助色服务产品识别，强调色不超过画面的 10%。

## 5. Material System

产品、接触面、道具和背景具有可信尺度、纹理、反射与使用痕迹。

## 6. Composition / Structure

一个产品、一个使用情境、克制道具与充足负空间，建立清晰的前中后景。

## 7. Photography Direction

使用可信的商业产品摄影机位、焦段、景深、光线与接触阴影。

## 8. Negative Rules

禁止产品合集、电商九宫格、悬浮拼贴、提案板、无使用逻辑的道具和 Anchor 具体画面复刻。
