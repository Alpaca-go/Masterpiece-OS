## 0. 文档目的

本文件用于统一“九州美学”空间效果图的生成方向与交付基准。

它不是一句只能逐字复制的死板提示词，而是一套可以作为 **交付校准标准** 的 Golden Prompt。它的目标是：

1. 统一九州美学空间效果图的视觉方向；
2. 约束模型不要偏向“概念装置图”或“泛美容院效果图”；
3. 保证输出结果具备真实可落地的空间设计感；
4. 保持与九州美学现有包装图、VI 图、品牌图形语言一致。

核心要求不是“只要好看”，而是：

> 先像一家真实可落地的高端医美空间，  
> 再像九州美学，  
> 最后才是氛围感与视觉装饰。

核心感受关键词：

- 专业可信
- 现代极简
- 珍珠白
- 矿物淡紫
- 东方秩序

- 轻盈羽瓣

# 2. 输入优先级

生成时必须按照以下优先级理解输入：

## P0｜Locked Assets

最高优先级，不得被风格化改写：

- 品牌名称：九州美学
- 英文名称：Jointown Aesthetics
- 已锁定 Logo 图形
- 已锁定品牌主色倾向
- 已锁定需要出现在空间中的品牌文案
- 用户提供的空间方向图、结构要求或功能分区信息
- 用户明确指定的空间类型（外立面 / 前厅 / 接待区 / 咨询区等）

## P1｜Golden Visual DNA

用于控制整套空间的稳定气质：

- 珍珠白、暖白、浅灰为主色
- 矿物淡紫、雾紫为辅助色
- 石墨黑或深灰用于文字信息
- 紫色品牌 Logo 作为识别核心
- 羽瓣、孔雀羽流线、九瓣放射、半透明虹彩花瓣结构为品牌图形母题
- 拱形空间、柔性曲线、一体化墙面、隐藏灯带
- 高级医美前厅 / 高端品牌门店的安静与秩序感

## P2｜当前任务变量

可根据任务发生变化：

- 空间类型
- 场景功能
- 外立面或室内
- 画幅比例
- 构图角度
- 昼景 / 傍晚 / 夜景氛围
- 品牌呈现方式
- 重点展示对象（门头 / 前台 / 海报 / 陈列）

## P3｜创意自由

仅允许在不破坏 P0–P2 的前提下发挥：

- 羽瓣装置的形态与位置
- 晶体摆件数量
- 灯带的位置与强弱
- 空间留白比例
- 弧形墙体的组织方式
- 产品陈列细节
- 局部光影层次

# 3. 品牌空间视觉 DNA

## 3.1 色彩结构

推荐空间色彩占比：

- 珍珠白 / 暖白 / 浅灰：65%–80%
- 矿物淡紫 / 雾紫 / 薰衣草紫：10%–20%
- 石墨黑 / 深灰文字：3%–8%
- 银灰金属：2%–6%
- 虹彩高光：不超过 5%

### 必须满足

- 空间整体必须明亮、低饱和、洁净、通透。
- 紫色只用于品牌点缀、Logo、灯光氛围和局部装置。
- 白色墙面与地面必须保留足够层次，不能死白。
- 整体氛围要像高端医美品牌，而不是普通美容院。

### 禁止

- 大面积深紫铺满空间。
- 高饱和霓虹紫。
- 黑紫金的俗艳奢华。
- 粉紫少女感。
- 夜店感、酒吧感、婚庆感。
- 彩色灯光过多导致空间失真。

---

## 3.2 核心图形语言

允许使用：

- 孔雀羽毛流线结构
- 九瓣放射结构
- 半透明羽瓣 / 花瓣
- 虹彩薄膜感
- 轻微圆环 / 放射线图形
- 低对比品牌纹样
- 墙面 Logo 组合
- 灯箱海报中的羽瓣图形

这些元素必须被表现为：

- 墙面品牌图形
- 发光 Logo
- 立式灯箱海报
- 前台一角的轻型艺术装置
- 局部亚克力或玻璃装置
- 柜体陈列中的小型视觉锚点
- 低对比压纹或淡化平面图形

不得表现为：

- 完整写实孔雀主体
- 大型奇幻雕塑主宰空间
- 魔法翅膀
- 游戏世界观场景
- 装饰堆满整面墙
- 复杂花卉图案覆盖空间

---

## 3.3 材质系统

优先材质：

- 微水泥
- 浅色石材
- 哑光金属
- 磨砂玻璃
- 通透玻璃
- 半透明亚克力
- 低反射地面
- 珠光饰面
- 灯箱膜材
- 精细涂料墙面

材质验收重点：

- 墙面、石材、玻璃、金属必须能被清楚区分。
- 石材要有细腻纹理，不可像塑料板。
- 金属必须克制、细腻，偏银灰，而非金灿灿装饰风。
- 发光边缘不能过曝。
- 玻璃门、灯箱、陈列结构必须具备真实厚度和安装逻辑。

---

# 4. 空间类型要求

## 4.1 外立面

如果任务是外立面，必须满足：

- 像真实可落地的高端品牌门店；
- 门头清晰，但不过度商业卖场化；
- 建筑外立面以浅灰、米白、石材或微水泥为主；
- 使用隐藏灯带勾勒轮廓；
- 有清晰入口仪式感；
- 可包含大幅竖向品牌灯箱海报；
- 海报与门头属于同一视觉系统；
- 可使用傍晚或夜景，但氛围必须安静优雅。

## 4.2 室内接待区 / 前厅

如果任务是室内接待区，必须满足：

- 接待台应为弧形或柔和曲线造型；
- 背景墙必须呈现九州美学主 Logo 墙；
- 品牌名、英文名、副标排版清晰；
- 可加入壁龛、层板或柜体展示包装产品；
- 可加入淡紫晶体摆件与半透明羽瓣装置；
- 整体应有医疗级洁净感与品牌前厅的接待感；
- 不能像酒店大堂，也不能像家装样板间。

## 4.3 咨询 / 功能过道入口

如果任务涉及功能区入口：

- 可在拱门侧墙加入清晰但克制的功能指示；
- 字体需高级、细腻、信息简洁；
- 不得使用医院导视那种强功能化粗暴排版；
- 必须与品牌空间整体气质统一。

---

# 5. 建筑与空间特征

空间必须尽量包含以下特征中的大部分：

- 大面积浅色立面
- 拱形门洞或圆角入口
- 弧形建筑轮廓
- 一体化曲面墙体
- 柔和隐藏灯带
- 发光门头或发光 Logo 墙
- 高级石材地面
- 极简展示壁龛
- 通透玻璃门
- 柔和曲面接待台
- 立式灯箱海报
- 局部晶体摆件
- 轻盈羽瓣装置
- 低噪音、秩序感强的空间组织

---

# 6. 灯光与氛围标准

## 6.1 主灯光

- 以暖白柔光为主；
- 整体照度均匀，空间明亮而不过曝；
- 通过隐藏光源表现高端质感；
- 墙面与地面保留细腻明暗层次。

## 6.2 辅助光

- 允许极弱淡紫边缘光；
- 允许局部灯带强调空间轮廓；
- 品牌 Logo 和羽瓣装置可带少量发光感；
- 灯箱海报可自发光，但必须柔和。

## 6.3 禁止

- 霓虹灯感；
- 强彩光污染；
- 强烈舞台灯；
- 大片过曝光晕；
- 空间局部死黑；
- 灯光把空间做成商业卖场或夜店。

---

# 7. 摄影视角与效果图标准

建议：

- 商业空间效果图视角；
- 轻微三分之四视角；
- 稳定透视；
- 视线高度接近真实人视角；
- 构图清晰，品牌识别明确；
- 重点展示门头、前台、海报、拱门或空间层次。

不得出现：

- 鱼眼畸变；
- 超广角导致空间变形；
- 不合理倾斜；
- 过度电影化景深；
- 过分情绪化镜头压过设计本身。

# 10. 一句话验收标准

用于交付校准时，建议采用以下总判断原则：

> 先看它是否像一家真实可落地的高端医美空间，

# 11. 六个核心验收点

## 11.1 品牌识别是否正确

- 九州美学 / Jointown Aesthetics 是否正确；
- Logo 是否正确；
- 品牌主视觉是否属于同一体系。

## 11.2 空间是否真实可落地

- 是否像真实商业空间；
- 是否具备门头、前台、墙体、地面、灯带等落地逻辑；
- 是否不是纯概念舞台或艺术装置图。

## 11.3 气质是否高端医美

- 干净、柔和、专业、可信；
- 不是泛美容院；
- 不是夜店式奢华；
- 不是家装样板间。

## 11.4 材质是否高级且真实

- 石材、微水泥、玻璃、金属是否真实；
- 发光结构是否可信；
- 是否避免塑料假质感。

## 11.5 紫色是否克制

- 淡紫作为点缀；
- 以白色和浅灰为主体；
- 不因追求品牌感而过度铺紫。

## 11.6 品牌视觉系统是否统一

- 与九州美学包装图、VI 图是否同属一套系统；
- 羽瓣、灯箱、Logo、空间线条是否彼此统一；
- 不得出现多套互相冲突的风格。

---

# 12. 总结

九州美学空间图的核心不是“紫色 + 高级感 + 一点羽毛元素”，而是：

> 通过真实、洁净、克制、可信的高端医美空间承载品牌专业度，  
> 再用珍珠白、矿物淡紫、羽瓣装置、发光 Logo 与柔性曲线，  
> 建立属于九州美学的品牌空间识别。
