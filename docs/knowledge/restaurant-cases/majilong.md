## 设计动作

1. **三跨门头做高低分区**：中跨最高，白色发光灯箱放品牌 + 绿色椭圆品类牌；左跨米色金属坡檐 + 英文名；右跨绿色格栅檐 + 三块权益牌（现场揉拉、续面、免费饮品）。
2. **左跨首层开街面窗做明档**：窗内白色瓷砖 + 不锈钢台，厨师现场穿串/烤制、揉面/拉面；窗下“炭火烧烤”绿色灯箱，窗上菜单灯箱。
3. **入口左侧深色石材柱做白色“现”字印章 + 竖排操作承诺**，柱旁放整幅牛肉面大图，形成食欲锚点。
4. **入口上方室内做一整排米色发光顶招**，每格一个大字，形成从街面可见的连续品牌带。
5. **室内用木框夹磨砂玻璃/条纹板做齐桌高矮隔断**，分隔卡座又不挡光；隔断上下藏灯带，形成横向节奏。
6. **后墙暗红肌理墙面 + 白色大字书法**，墙顶一条绿色小方砖带，嵌木框绿色印章牌；桌面/餐具用绿色呼应。
7. **家具浅木色桌 + 黑座脚 + 米色坐垫卡座**，桌边嵌绿色桌号/点餐牌；地面浅灰水磨石/仿石砖，整体轻、耐看、易清洁。
8. **物料用铜青绿 + 米白 + 落日橘**，波纹线/“隆”印章贯穿打包袋、围裙、菜单、海报，形成空间外的品牌延续。

## 成立前提（均为推断）

- 门面有三跨宽度和足够层高，才能做“中跨高、两翼低”的层级；否则门头会碎。
- 左跨具备开窗、排烟、补风条件，才能把烧烤/拉面操作前置到街面；否则油烟会倒灌。
- 进深足够容纳“街面明档—入口—前场—后厨”的序列；进深太浅会把油烟和排队带进座区。
- 所在城市有全天候/夜宵客流，8:00–24:00 与夜景门头才成立。
- 兰州牛肉面品类认知强，品类牌可以独立成立；若品类陌生，需要更多解释性画面。

## 禁止 / 误用

- 不能开街面窗、排烟不达标时，不要做“现串现烤”明档，油烟会倒灌。
- 门面不是三跨、宽高比不够时，不要硬套“中高两低”三分法，会碎、会挡。
- 层高不足时，不要做多层叠级门头 + 整排发光顶招，会压。
- 不是兰州牛肉面/西北面食品类，不要直接套铜青绿 + “隆”印章 + 西北叙事，会被误认。
- 不要轻率承诺续面/免费饮品，除非成本模型和供应链能长期兑现。
