# 下一阶段冯烫烫设计质量审核建议

本轮只接受候选实现的代码完整性，**没有视觉质量验收**。真实分析、生图、模型校验及自动重试均为 0；未批准知识卡、未修改历史质量记录。以下为单独阶段的审核建议，不构成真实 Provider 调用授权。

先由用户/设计师逐镜头确认当前目标与输入：社区临街特色小馆、亲民日常、堂食与外带关系是否仍适用；品牌与品类文字维持后期合成，不以直接模型文字渲染绕过既有语义门禁。历史派生 Packet、用户目标、项目观察和未确认假设要分别标明，不能把本次离线对照当作图 1 的实际 Run。

| 审核项 | 需要的决定与证据 |
| --- | --- |
| storefront/front | 审核立面、门头、门槛和街道关系；未批准的室内活动继续不渲染。若确需隔窗展示厨房、制作或顾客，先处理独立权限接口，不用玻璃材质自动授权 |
| entrance/entrance_view | 只呈现有来源的入口局部活动；完整点餐→制作→取餐→就餐网络继续作为经营依赖审阅，不要求同框展开全店 |
| dining/three_quarter_wide | 确认厨师制作、热气、桌边顾客的场景适用性及实际视线；保持各自清晰 owner 与去重，不因历史文本存在就认定真实布局成立 |
| 模板措辞 | 分别审核 `gallery-like` 的可选气质、`premium/high-end` 的渲染质量含义、`reception/waiting/privacy` 的通用语境，以及负向 clinic guard；先区分正向污染、气质偏向和负面防污染，不一键删除 |
| 材料与光 | 红砖、暖木、赤陶、暖光只作项目方向候选。旧红金属/塑料、半通透格栅、3000–3500K、射灯和反射参数逐项审查；未知构造/光学行为继续未知，不凭旧效果图编造 |
| 不确定事实 | 物业尺寸、开放厨房许可、厨房位置、经营比例、顾客情况和窗口可见范围需要来源或明确假设；不由地域、品牌或行业直接推定风格 |

只有输入、镜头权限、材料方向和模板风险经设计审阅后，才建议另行提出有预算的真实 A/B 方案：同镜头内保持模型、参数、参考图策略和其他控制一致，预先写明评价标准，完整保留失败与成功结果；记录 Provider/model、终态、调用次数、时长、报告/图片路径、Logo 合成结果和人工评价。不得用关键词数量、Prompt 长度或离线测试分数替代视觉判断。

任何真实调用、输入修订、窗口权限、模板/材料系统修改或质量记录更新都须进入后续明确授权范围。本轮到此停止，不进行这些操作。
