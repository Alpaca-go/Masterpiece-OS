## 3. 设计决策与建议

### 3.1 Reference First (参考优先)
*   **传统与现代的平衡**：设计决策明显倾向于“新中式”。使用红色印章和宋体字保留传统中医的权威感，但通过几何化的“良”字Logo和圆润的专用字体注入现代感，避免过于陈旧。
*   **色彩心理学**：棕色系让人联想到中草药、大地、温暖；红色系代表生命力、血液、传统印章。这种组合非常适合中医健康管理行业。

### 3.2 Space (空间与安全区域)
*   **安全空间 (Clear Space)**：
    *   以“X”为基本单位（注：关于X的具体定义见第4节限制）。
    *   限制区域内不得出现任何文字、符号。
    *   建议在实际应用中，至少保留 0.5x - 1x 的周边空白，确保Logo呼吸感。

### 3.3 Packaging & Application (包装与应用)
*   **药柜标签**：设计非常具体。白底，黑字（药材名），背景叠加淡色拼音和Logo水印。这种设计既实用（清晰可读）又具有品牌统一性。
*   **诊疗单/文件夹**：
    *   **诊疗单**：顶部棕色色块反白Logo，右侧大字“诊疗单”，底部公司信息。
    *   **文件夹**：封面满版棕色+巨大浅色Logo水印；内页右下角局部棕色色块+Logo。
*   **深色模式**：提供了黑底白字的反白方案，适用于夜间模式或深色材质印刷。

## 4. 限制与不确定性

1.  **色彩数值标注错误**：
    *   在 `C01-10 品牌色盘` 中，最右侧白色色块的 Hex 代码被错误标注为 `#B00000`（与红色相同），但其下方的 RGB (255, 255, 255) 和 CMYK (0, 0, 0, 0) 以及色块本身均显示为白色。在实际执行中应以 **白色 (#FFFFFF)** 为准。
2.  **安全空间单位 "X" 的定义歧义**：
    *   在 `C01-33 比例与安全空间` 中，文字描述称“将图形标志的高度作为一个标准单位，并设为X”。
    *   然而，图示标注中，图形标志（红色图标）的高度被标注为 `2.6x`，宽度也被标注为 `2.6x`。
    *   这表明图文之间存在矛盾：要么 X 不是图标高度（可能是笔画宽度或某个更小单位），要么标注数字有误。建议在制作物料时，以图示的相对比例为准（即图标高度 : 文字宽度 ≈ 2.6 : 5.9），或者重新定义 X 为图标高度的 1/2.6。
3.  **字体版权**：
    *   指南指定使用“思源宋体”。思源宋体是开源字体（SIL Open Font License），商业使用通常免费，但仍需确认具体版本的授权条款。
    *   “一剂良方”的专用字标版权归属需确认。
4.  **Logo 颜色限制**：
    *   `C01-12` 明确指出不可修改 Logo 颜色（如将红色图标改为金色）。这意味着在单色印刷（如只有一种专色）时，可能需要使用反白或纯黑/纯棕版本，而不能随意改变色相。深色模式（C01-30）已提供了白字方案。
