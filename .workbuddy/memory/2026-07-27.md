## Bug 修复：API 配置页 dashscope 连接测试误报 400（commit `4a8d426`）

### 现象
用户在「API 与模型」设置页测试 dashscope（图像生成）Profile，报 `连接失败（HTTP 400）: Bad Request`，红字阻断。

### 根因
`apps/desktop/src/main/settings-store.ts` 的 `connectionRequest` 对所有 provider 统一发送 **OpenAI 兼容 `/chat/completions` 视觉测试**（图片+文字）。但 DashScope 生图实际接口是 `POST /api/v1/services/aigc/text2image/image-synthesis`，`wan2.7-image-pro` 不支持聊天格式 → 服务器返回 400。这不是 Key 无效（401 才是 Key 问题），是测试方法不匹配。

### 修复
- 新增 `dashScopeConnectionRequest`：改用 `GET /api/v1/tasks/<探针UUID>` 探测，校验 API Key 与 Endpoint 可达性，**不消耗调用额度**（401/403=Key 无效；404/400/429=鉴权通过、探针 task 不存在/限流，均返回连接成功；5xx=服务端错误）。
- `connectionRequest` 顶部按 `provider === 'dashscope'` 分支。
- 自验：桌面 typecheck 0 错；桌面测试 133/133。
- 注意：该连接测试原无单元测试（走真实网络），本次未补测试（可纳入 Phase 6）。
