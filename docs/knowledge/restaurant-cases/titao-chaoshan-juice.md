## 设计动作

1. **门头做"木匾 + 黑字"**：一块竖向木匾写"踢桃 潮汕果汁冰"，下面配灯箱菜单，形成"老铺匾额 + 现代灯箱"的混搭。
2. **草绿做唯一记忆色**：只出现在字标、灯箱边、柜体踢脚、包装小面积块；墙面保持米白与木色。
3. **灯箱菜单明码标价**：黑字白底，产品照片 + 价格（¥20 一类），价格是版式的一部分，不回避。
4. **台面做双层**：前层收银/点单，后层出杯；台面浅色，柜体木色，台下留踢脚线。
5. **墙面留白 + 单字书法**：墙面只放一两块书法字牌与手写小海报，不做整墙图形。
6. **包装走牛皮纸 + 草绿块**：手提袋、杯套、瓶贴统一；杯子是白色 + 绿字。
7. **小道具做地域感**：竹椅、木牌、手写价签——用"器物"而不是"图案"表达潮汕。

## 成立前提（均为推断）

- 档口面积小（10–30 ㎡ 量级），只能做柜台与外带，不能有后厨明火。
- 品类单价低、出杯快，价格必须明示，否则顾客要问三次。
- 商场/街面对灯箱亮度与尺寸有规范；木匾属于外挂物，需要审批。
- 草绿 + 米白 + 木色在强光下才不发灰；暗场里会显脏。

## 禁止 / 误用

- 正餐、需要久坐的场景不要用"小柜台 + 明码标价灯箱"，会把客单压死。
- 深色木 + 暗光的空间不要用草绿，会变脏。
- 书法匾额属于强地域语言：不是潮汕/岭南品类时容易变成"假装老字号"。
- 不要直接复制"踢桃"字标、书法、草绿配色与灯箱版式。
