# 九州美学空间效果图 Golden Acceptance Standard

> 文档版本：v1.0  
> 适用项目：九州美学品牌空间效果图  
> 适用用途：交付验收 / 自动评分 / 人工复核 / 生图校准  
> 文档性质：Golden Acceptance Standard（评分版）  
> 状态：可直接用于当前九州美学空间效果图垂直测试

---

## 0. 文档目的

本文件用于作为 **九州美学空间效果图的统一验收标准**。

它不解决“提示词怎么写”的问题，而是解决：

1. 这张空间图是否合格；
2. 这张图是否已经达到“可交付”标准；
3. 当结果不合格时，应归因为哪一类问题；
4. 下一轮该如何修正。

本标准适用于：

- 门店外立面效果图
- 前厅 / 接待区效果图
- 咨询区入口 / 过道入口图
- 大厅空间效果图
- 空间品牌展示图

---

# 1. 总体验收原则

九州美学空间图的总判断原则是：

> **先判断它是否像一家真实可落地的高端医美空间，**  
> **再判断它是否属于九州美学，**  
> **最后才判断氛围是否足够漂亮。**

也就是说，验收优先级为：

1. **真实性 / 可落地性**
2. **品牌识别正确性**
3. **空间气质是否匹配高端医美**
4. **视觉系统是否统一**
5. **效果图完成度与高级感**

如果一张图只是“很好看”，但：

- Logo 错误；
- 空间不像真实门店；
- 透视失真；
- 风格偏成夜店或婚庆；

则应判定为 **不合格**。

---

# 2. Golden Outcome Definition

一张通过验收的九州美学空间效果图，必须满足以下总体状态：

> 它应当呈现为一家真实、专业、洁净、温柔、克制、具备品牌识别的高端医美空间。  
> 空间语言统一，材质高级可信，淡紫只作为品牌点缀，羽瓣与 Logo 以空间图形语言融入其中，能够直接进入品牌提案、客户汇报或落地参考阶段。

用户看到合格图时，首先应该感受到：

- 这是一家靠谱的高端医美品牌；
- 它有统一品牌系统，而不是临时贴个 Logo；
- 它真实可建，而不是概念舞台；
- 它属于九州美学，而不是任何一个泛医美空间。

---

# 3. 验收前置条件

在评分前，必须先明确该图属于哪一种任务类型：

## 3.1 任务类型分类

- `storefront`：外立面 / 门店入口
- `reception`：前台 / 接待区
- `lobby`：大厅 / 品牌前厅
- `consult_entry`：咨询区入口 / 功能过渡区
- `mixed_brand_space`：品牌综合展示空间

## 3.2 输入基准

验收时，必须同时对照以下输入：

1. 已锁定品牌资产（Logo、品牌名、英文名）
2. 九州美学包装与 VI 已建立的视觉系统
3. Space Golden Prompt（空间专用 Golden Prompt）
4. 当前任务指定的空间类型与画幅要求
5. 用户额外说明（如傍晚氛围、前台、功能标识等）

---

# 4. 一票否决 / 硬失败条件

出现以下任意一项，直接判定为 **Fail**，不进入常规打分：

## 4.1 品牌类硬失败

1. 品牌名称错误（“九州美学”错误或缺失）
2. 英文名错误（Jointown Aesthetics 错误或缺失）
3. Logo 被替换、严重变形或风格错误
4. 海报 / 墙面主品牌与空间品牌不一致

## 4.2 空间真实性硬失败

5. 空间明显不像真实商业空间，只像概念装置图
6. 门头、前台、玻璃、墙体、地面等结构关系不成立
7. 透视严重错误，无法用于提案
8. 灯箱、门洞、前台等核心构件明显无法落地

## 4.3 风格方向硬失败

9. 画面偏成夜店 / 酒吧 / KTV / 婚庆展厅风格
10. 大面积高饱和霓虹紫，严重偏离九州美学视觉系统
11. 欧式宫廷 / 浮夸装饰 / 厚重奢华风严重偏离项目方向
12. 生成完整写实孔雀或奇幻魔法场景作为主体

## 4.4 交付可用性硬失败

13. 画面主体不清，无法判断空间类型
14. 文字大面积乱码且影响主体判断
15. 材质严重塑料感 / 低端感，完全不具备高端医美可信度
16. 整体结果无法支持正式汇报或客户提案

---

# 5. 总分结构

总分 **100 分**，建议：

- **90–100 分：Pass（可直接交付）**
- **80–89 分：Pass with minor revision（可小修后交付）**
- **70–79 分：Revise（方向基本对，但必须修正后再交付）**
- **0–69 分：Fail（不合格，建议重生或重构）**

---

# 6. 八大评分维度

## 6.1 品牌资产正确性｜20 分

衡量：这张图是否确实属于“九州美学”。

| 检查项 | 分值 |
|---|---:|
| 中文品牌名正确 | 4 |
| 英文名正确 | 2 |
| Logo 图形正确 | 5 |
| Logo 使用位置合理 | 3 |
| 空间海报 / 前台 / 门头品牌统一 | 4 |
| 品牌副标与信息层级合理 | 2 |

### 合格表现

- 门头、前台墙或主海报明确出现“九州美学”；
- Logo 样式一致，不随意变体；
- 品牌识别清晰但不堆砌。

### 扣分典型

- 只有 Logo 没有品牌名；
- 中文对了，英文乱了；
- 同一张图中 Logo 风格不一致；
- 品牌像后贴上去，不属于空间系统。

---

## 6.2 空间真实性与可落地性｜20 分

衡量：这是不是一张可以进入空间提案的真实空间效果图。

| 检查项 | 分值 |
|---|---:|
| 结构逻辑成立（门洞 / 前台 / 墙面 / 地面） | 5 |
| 透视准确稳定 | 4 |
| 构件可建性强 | 4 |
| 动线与功能关系合理 | 3 |
| 门店 / 前厅识别清楚 | 2 |
| 不是纯概念装置图 | 2 |

### 合格表现

- 门店入口、接待台、灯箱、玻璃门等关系自然；
- 一眼能判断为空间效果图，而不是海报装置场景；
- 可直接作为设计提案视觉参考。

### 扣分典型

- 空间边界不清；
- 门不能开、前台无尺寸感、灯箱没有安装逻辑；
- 建筑透视飘、场景像舞台布景。

---

## 6.3 医美空间气质匹配度｜15 分

衡量：它是否真正像“高端医美空间”。

| 检查项 | 分值 |
|---|---:|
| 洁净感 | 3 |
| 专业可信感 | 3 |
| 温和与高级感 | 3 |
| 克制而非俗艳 | 3 |
| 医美属性明确而非泛美容院 | 3 |

### 合格表现

- 干净、安静、温柔但不软弱；
- 像高端医美 / 轻医美 / 皮肤管理品牌前厅；
- 兼具商业属性与品牌质感。

### 扣分典型

- 像普通美容院；
- 像样板房、酒店或展厅；
- 奢华过度，失去医疗级可信度。

---

## 6.4 视觉系统一致性｜15 分

衡量：它是否和九州美学已有包装、VI、海报系统属于同一套语言。

| 检查项 | 分值 |
|---|---:|
| 珍珠白主色成立 | 3 |
| 淡紫控制克制 | 3 |
| 羽瓣 / 九瓣图形语言统一 | 3 |
| 与包装图语言统一 | 3 |
| 与门头、海报、前台互相统一 | 3 |

### 合格表现

- 白为主、紫为辅、虹彩轻点缀；
- 羽瓣图形以同一语言出现；
- 与之前的包装与 VI 图连成一套系统。

### 扣分典型

- 空间图是另一套风格；
- 紫色过多、海报很华丽但前台很普通；
- 包装系统与空间系统脱节。

---

## 6.5 材质与工艺可信度｜10 分

衡量：空间材质是否高级、真实、可实现。

| 检查项 | 分值 |
|---|---:|
| 石材表现真实 | 2 |
| 墙面 / 微水泥表现真实 | 2 |
| 玻璃与灯箱结构真实 | 2 |
| 金属细节细腻 | 2 |
| 发光与材质关系可信 | 2 |

### 合格表现

- 石材、墙体、玻璃、金属可明确区分；
- 没有廉价塑料感；
- 发光 Logo 和灯箱不会溢出失控。

### 扣分典型

- 整个空间像塑料渲染；
- 灯带过曝；
- 墙体像白色泡沫板；
- 金属像玩具。

---

## 6.6 光线与氛围控制｜8 分

衡量：灯光是否支撑高端医美空间感。

| 检查项 | 分值 |
|---|---:|
| 整体照明柔和自然 | 2 |
| 白色层次保留完整 | 2 |
| 紫色光控制得当 | 2 |
| 氛围安静高级 | 2 |

### 合格表现

- 整体明亮但不过曝；
- 紫色只作边缘光或氛围补光；
- 空间像高端品牌门店，而非彩光展厅。

### 扣分典型

- 紫光太强；
- 白色死白；
- 局部发黑；
- 光影太戏剧化，破坏品牌安定感。

---

## 6.7 构图与展示重点｜7 分

衡量：画面是否清楚传达本次要展示的空间重点。

| 检查项 | 分值 |
|---|---:|
| 主体明确 | 2 |
| 构图稳定 | 2 |
| 品牌识别在合理位置 | 1 |
| 空间层次清晰 | 1 |
| 没有杂乱干扰 | 1 |

### 合格表现

- 外立面图能看清入口、门头与灯箱；
- 前台图能看清接待台、品牌墙和空间分区；
- 视觉重心清晰，不乱。

### 扣分典型

- 不知道主角是门头还是海报还是装置；
- 前景干扰过多；
- 视角奇怪，品牌被裁切。

---

## 6.8 商业交付成熟度｜5 分

衡量：它是否已经具备“可交付”状态。

| 检查项 | 分值 |
|---|---:|
| 可直接用于提案汇报 | 2 |
| 不像 AI 概念草图 | 1 |
| 具备品牌呈现完成度 | 1 |
| 可以支持后续延展 | 1 |

### 合格表现

- 画面完成度高；
- 不只是情绪图；
- 可作为客户展示材料。

### 扣分典型

- 虽然好看，但不能用；
- 信息不完整；
- 主体不够明确；
- 缺乏品牌商业空间的说服力。

---

# 7. 任务类型专项加权检查

不同空间类型，除了总分，还应补充专项检查。

## 7.1 外立面专项检查

附加关注点：

- 门头尺度是否合理
- 入口是否有仪式感
- 灯带与门头是否协调
- 海报与建筑是否融合
- 玻璃门与室内透视是否真实

典型失败：

- 门头像美容院；
- 海报喧宾夺主；
- 建筑外墙质感廉价；
- 发光太像街边商铺。

## 7.2 前台 / 接待区专项检查

附加关注点：

- 接待台造型是否高级
- 台面是否干净
- 背景品牌墙是否成立
- 导视与接待功能是否明确
- 陈列与装饰是否克制

典型失败：

- 前台像酒店；
- 台面杂乱；
- 品牌墙像后贴字；
- 晶体或羽瓣装置过多，抢掉接待功能。

## 7.3 大厅 / 前厅专项检查

附加关注点：

- 空间是否有迎宾感
- 品牌主视觉是否建立
- 层次与尺度是否充足
- 不同功能区是否有逻辑过渡

典型失败：

- 太空、太虚，没有真实使用感；
- 视觉重心全散；
- 品牌识别不足。

# 8. 常见失败标签（Failure Tags）

建议在自动验收或人工复核时，为不合格图打上失败标签：

- `brand_name_wrong`
- `logo_drift`
- `brand_system_inconsistent`
- `space_not_realistic`
- `perspective_broken`
- `too_much_purple`
- `nightclub_feel`
- `beauty_salon_generic`
- `material_too_cheap`
- `lighting_overexposed`
- `lighting_too_dark`
- `poster_overpowering`
- `reception_not_clear`
- `storefront_not_convincing`
- `too_fantasy`
- `commercial_readiness_low`

---

# 9. 修正动作映射（Revision Actions）

| 失败标签 | 建议修正动作 |
|---|---|
| `brand_name_wrong` | 强化品牌资产权重，锁定九州美学中英文与 Logo |
| `logo_drift` | 直接传入 Logo 资产，禁止自由变体 |
| `brand_system_inconsistent` | 引入包装 / VI Anchor 图保持系统统一 |
| `space_not_realistic` | 减少装置感，强化门头、前台、墙体、地面真实结构 |
| `perspective_broken` | 改为标准商业空间视角，降低夸张镜头 |
| `too_much_purple` | 提升珍珠白比例，削弱大面积紫光和紫面 |
| `nightclub_feel` | 删除霓虹感与彩光，回到暖白柔光 |
| `beauty_salon_generic` | 强化高端医美前厅特征，减少普通美容院陈设 |
| `material_too_cheap` | 强调石材、微水泥、哑光金属、玻璃层次 |
| `lighting_overexposed` | 压低灯带与灯箱曝光，保留白墙层次 |
| `lighting_too_dark` | 提升整体照明，增强高端空间通透感 |
| `poster_overpowering` | 缩小海报占比，提升建筑和品牌主体关系 |
| `reception_not_clear` | 放大前台、清晰展示品牌墙与接待台 |
| `storefront_not_convincing` | 强化入口结构、门头尺度和玻璃门逻辑 |
| `too_fantasy` | 删除完整孔雀、魔法、奇幻装置，保留抽象羽瓣 |
| `commercial_readiness_low` | 简化无用噪音，增强品牌完成度和提案成熟度 |

# 10. 标准验收流程

建议采用如下流程：

## Step 1｜硬失败检查

先判断是否命中 16 项硬失败条件。  
若命中任一条，直接输出：

- `final_decision = fail`
- `fatal_check_result = true`
- `failure_tags = [...]`

## Step 2｜8 大维度打分

若无硬失败，则对以下 8 项逐项打分：

1. 品牌资产正确性｜20
2. 空间真实性与可落地性｜20
3. 医美空间气质匹配度｜15
4. 视觉系统一致性｜15
5. 材质与工艺可信度｜10
6. 光线与氛围控制｜8
7. 构图与展示重点｜7
8. 商业交付成熟度｜5

## Step 3｜得出结论

- 90–100：`pass`
- 80–89：`pass_with_minor_revision`
- 70–79：`revise`
- 0–69：`fail`

## Step 4｜输出修正建议

输出至少包含：

1. 最严重的 3 个问题
2. 对应 failure tags
3. 下一轮修正动作
4. 是否可进入正式交付

# 13. 总结

九州美学空间效果图的验收核心，不是“紫色够不够明显”，也不是“氛围够不够仙”，而是：

> **它是否真实、专业、可信、统一，并且明确属于九州美学。**

正确的高分结果，应当同时满足：

1. 一眼看出是高端医美空间；
2. 一眼看出是九州美学；
3. 一眼看出能落地，不是概念泡影；
4. 再进一步，才是高级与好看。
