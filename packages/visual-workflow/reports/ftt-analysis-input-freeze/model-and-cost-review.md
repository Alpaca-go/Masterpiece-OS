## 停止规则

1. 项目、素材、阶段正文、源码、模型、完整 URL 或会话/账本漂移：发送前拒绝。
2. 连接/超时/重定向/HTTP 错误、缺 request ID、异常终态、无效 JSON、响应模型不符、usage 缺失/非法、无匹配费率：终止，已保留次数不退，不续发第二次或第三次。
3. 账单金额、计费方案或 usage 归属出现未知/冲突时，停止后续执行并保留未对账状态，不能把 unknown 记作 ¥0。不得为查账补发模型请求；需要额外账户访问时另行授权。
4. 当前监护器仅根据返回 usage 和冻结费率计算估算，没有账单查询接口，也无法实时证明账单结算无异常。已观察到的账单异常必须人工停止；不能声称代码会自动发现所有远端计费异常。正常 usage 估算记录也不能冒充已对账账单。

最终授权需明确接受以上风险。授权仅放行该固定会话的一次正式 analyze，不给其他模型、模型探测或生图额度。
