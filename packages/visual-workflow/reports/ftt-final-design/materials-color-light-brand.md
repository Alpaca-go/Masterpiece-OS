# 材料、色彩、照明及品牌表达审核矩阵

A=本轮用户设计目标；B=历史人工经验；C=历史 AI/Prompt 提案；D=未确认方案。动作只针对实验副本，所有原始记录保持不变；B 字段的填充不等于材料工程参数已获证实。

| 项目 | 来源层级 / 证据 | 建议动作 | 核心 B 中的处理 | 待人工决定 |
| --- | --- | --- | --- | --- |
| 暖色木 | B：evaluation.materialAndLighting.note；C：原浅木提案 | **保留方向** | 暖色木综合色调，木种/纹理尺度/涂层/光学未知；不反推工艺 | 使用部位、色样与实际做法 |
| 赤陶 | B：同一人工 note | **保留方向** | 暖赤陶综合色调；不预设地砖、墙砖、釉面或整铺比例 | 制品形式与位置 |
| 红砖 | C：历史 Prompt anchor；项目 candidate rks-observation-3 | **待确认，暂不应用核心** | 不写入 B 材料列表；不伪称该人工 note 已验收红砖 | 是否需要砖、用于哪里，是否适合当前店型 |
| 红色金属/塑料 | C：Packet.materialSystem[1] | **替换默认地位，保留可选审查** | 不沿用红金属高反射/塑料哑光为必备视觉；品牌红另审 | 不全局禁止现代金属设备；若选载体需明确部位/表面 |
| 浅石材/瓷砖 | C：Packet.materialSystem[2] | **撤去全空间默认背景，待确认** | 核心 B 不强制整墙整地浅石面；保留卫生、清晰工作面的目标 | 必要操作/清洁区域具体材料，避免推成冷白样板间 |
| 半通透木格栅 | C：structureLanguage[1] | **删除本轮必备要求** | 开放式布局保留，格栅构造不应用 | 是否确有分隔/视线需求；不以透明度自动授权厨房可见 |
| 木质家具、餐桌、人尺度 | B：历史 Prompt 木 booth；D：本轮桌椅/服务通行关系 | **保留人尺度目标，替换尺寸/网格硬约束** | 一条明确的桌椅与双侧通行方案文本；不指定座高、桌高、间距、数量 | 家具类别、布局与实际通道条件 |
| 暖色照明、厨房与食物可读 | A：温暖/真实经营；B：厨房暖光 | **保留** | 定性温暖、明亮可读、不过曝；不新增精确参数 | 实际光源、现场条件与视觉取舍 |
| 暖光结合自然光 | C：历史 Prompt 自然光；D：当前适用性 | **保留选项，待确认** | 不强制新增窗户或开口，非堂食核心硬要求 | 是否有可用开口、光照方向及所需时段；缺证仍未知 |
| 3000–3500K、射灯 | C：lightingSystem | **删除当前执行数值/灯具硬要求** | B 只保留定性光感，没有换成另一个编造数值 | 如未来需要，另有设计依据再选，不由旧图反推 |
| 高反射/漫反射/半透明等参数 | C：旧材料和格栅 | **待确认，不继承为事实** | 明确“光学参数未指定”；保留真实材料可读的技术目标 | 材样或设计说明，不能以历史暖光认可替代 |
| 品牌红、品牌黑 | C：原资产分析/配色；A：明确品牌特色 | **保留名称供审阅，替换范围暗示** | 名称保留为提案；表面、色值、面积比例未指定，未新加 userConfirmedFields | 当前原资产、应用范围及是否需要更大红色表面 |
| 木色、白色 | C：原配色；B：暖木；D：新场景范围 | **保留辅助候选** | 不由 primary/accent 排名推定面积；不强制白色成为整店主背景 | 综合色调与暖色材料的比例，不能凭空填百分比 |
| 整体冷淡/冷白印象 | A：温暖亲切目标；C：旧蓝绿大面积禁令 | **替换笼统禁色要求** | 不以冷淡空间替代暖氛围；撤去旧蓝绿整体禁令的自动继承 | 允许卫生设备局部白光/金属；不将其当作错误极简风格 |
| 开放明档、制作/热气/服务/顾客 | A：真实经营；B：人审经营关系；D：本轮具体同框表达 | **保留堂食优先方案** | 核心行为在 dining 得到 owner；入口与外立面各自限制 | 真实开放厨房条件、可见范围、食物与人物合理性 |
| 临街玻璃营业氛围 | A：本轮明确保留目标；D：具体厨房可见映射 | **待确认，当前 withheld** | 原句保留在 source/trace，正式 Prompt 不输出厨房玻璃行为 | 必须先审核 window visibility；不能因玻璃目标阻塞已准备好的 dining |
| Logo、店名、品类文字、Slogan | A：品牌特色；历史 lockedAssets/原资产记录 | **保留后期合成** | A/B 都将原硬可见文字 0/1/3 项移至公开人工清单，B 不要求模型写字 | 当前有效原文件、使用许可、位置、尺度及合成确认 |
| 灯笼、脸谱、非遗/老字号叙事 | C：旧资产/提案；A：不虚构品牌定位 | **删除必备关系，不创造全局禁令** | 不把地域自动翻译成固定装饰，也不生成新的文化背书 | 若原 Logo 自带图形须保真；是否可用的事实/文案另外审核 |

历史 Prompt 还包含 1.5m、45cm、75cm、1.2m 等具体尺寸，本轮没有把它们迁入 B。它们既不是本轮测量，也不由图片推导。材质组合只适用于本项目待确认方向，不写为四川餐饮、社区餐饮或全行业规则。
