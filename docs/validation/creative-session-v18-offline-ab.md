# Creative Session V18 离线 A/B 验证

验证范围：冯烫烫室内空间、九州美学品牌海报、简单包装项目包装渲染。

本报告只记录不调用真实 Provider 的合同级验证，不声称代表最终图片质量。

| 项目 | 旧流程风险基线 | 新流程离线结果 |
| --- | --- | --- |
| 冯烫烫 | 室内任务可能退化为 VI 多物料平铺 | 固定为一个完整室内空间，禁止拼贴和多格合集 |
| 九州美学 | 海报任务可能扩展为物料合集 | 固定为单一海报主画面 |
| 简单包装项目 | 包装任务可能缺失明确交付责任 | 固定为一个真实包装渲染结果 |

共同验证结果：

- Final Prompt 以用户本次任务为最高优先级；
- Provider 参考图不超过 3 张；
- `reading_only` 资产不进入最终参考集；
- 身份参考最多 1 张，结构参考按任务选择；
- 最近反馈最多继承 5 条，避免无限增长；
- Same Instruction Retry 不重新执行 Reading；
- Session 重启恢复、旧 Run 读取和 Desktop 构建由自动化回归覆盖。

最终视觉一致性评分与 Provider 成本、时长、图片下载结果，必须在用户授权真实 API 测试后补录。
