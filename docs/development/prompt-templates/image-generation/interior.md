# Interior Scene Template

Template Version: 1.0.0

## 1. Task Definition

Create one complete, commercially credible interior scene that demonstrates how the approved brand system behaves in a real customer environment.

## 2. Brand Context

Use `visualMemory.brand_core`: positioning, industry, mood, and core temperament.

## 3. Visual Mechanism

Translate the approved graphic language into spatial rhythm, wayfinding, service nodes, and restrained identity moments. Do not turn the scene into a VI presentation board.

## 4. Color System

Establish a dominant environmental base, a supporting brand layer, and an accent layer capped at 10%. Preserve approved brand relationships and reject colors listed by negative rules.

## 5. Material System

Describe real architectural materials, finish behavior, joinery, tactility, reflectivity, and production credibility.

## 6. Composition / Structure

Show foreground, middle ground, background, circulation, service functions, floor, walls, ceiling, furniture, and spatial depth in one continuous scene.

## 7. Photography Direction

Use a human-eye architectural viewpoint, controlled wide-angle perspective, corrected verticals, believable exposure, and commercially usable lighting.

## 8. Negative Rules

No flat VI collections, moodboards, split screens, portfolio grids, isolated Logo walls, surface-only reskins, or copies of the previous visual scheme.
