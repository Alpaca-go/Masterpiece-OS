# S4.2 Target Runtime Map

## Current topology after S4.2

```text
Web Renderer
  -> Local RPC
  -> Electron Host (temporary)
     -> lifecycle / BrowserWindow
     -> settings + credential adapters
     -> dialogs / shell / event bridge
  -> Shared Operation Registry
  -> Shared Runtime
     -> Project Runtime
     -> Analysis Runtime
     -> Document + Context Runtime
     -> Reference Runtime
     -> Image / Space / Packaging Runtime
     -> Creative Production Runtime
  -> Shared Core
```

## Ownership boundary

| Layer | Owner | Allowed host knowledge |
|---|---|---|
| Domain capability | Shared Core packages | None |
| Application orchestration and persistence semantics | `@masterpiece/runtime-core` | Injected config, credentials, paths, storage/event callbacks |
| Business dispatch | Shared Operation Registry | Operation ID, arguments and execution context only |
| Current host | Electron Desktop | IPC/RPC binding, lifecycle, native UI, safeStorage and adapters |
| Future host | Node host in S4.1R | RPC binding and Node equivalents of the same adapters |

## S4.1R replacement seam

S4.1R replaces only the Electron host/adapters above the registry. It must reuse `createRuntimeServices(...)`, `createSharedRuntime()` and the same operation factories; it must not duplicate application services.
