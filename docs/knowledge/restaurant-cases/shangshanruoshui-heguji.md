## 设计动作

1. **深绿做主色，黄铜做唯一金属色**：门头、包装、围挡、制服领口统一深绿；铜印、吊灯、把手用黄铜，不用彩色金属。
2. **门头做“深绿底 + 白色宋体字”**：不做大面积背光，字是唯一亮点；开业期用深绿围挡 + 白字“即将开业”延续同一套版式。
3. **室内用深木格栅做半透隔断**：格栅到顶、间距宽，既分区又不封死视线；包厢用整木包。
4. **白桌布 + 深木椅 + 黄铜吊灯**：桌面保持白，靠木与铜压住“家常”的随意感；吊灯低垂，光落在桌面。
5. **包厢做整木圆桌 + 软包墙**：圆桌居中、无主灯，靠吊灯与壁灯做层次。
6. **物料走“深绿 + 米白 + 铜”**：包装袋、木盒、筷子套、折扇、标签；铜印“和”作为记忆点。
7. **用稻谷/麦田照片做品牌摄影**：产地叙事靠实拍作物，不靠插画。
8. **制服做白底绿领立领**：没有大 logo，只在袖口/领口做小字。

## 成立前提（均为推断）

- 品类是“家常粤菜”且客单能支撑白桌布、包厢与铜器维护。
- 门店有足够层高做深色顶棚与低垂吊灯，否则会压抑。
- 有稳定的白桌布洗涤与更换能力；白桌布是这套气氛的底线。
- 开业期围挡与门头是同一套视觉，说明有品牌管理方；单店复制需要设计方持续供给物料。
- 深绿 + 黄铜在暖光下容易发暗，需要足够的重点照明。

## 禁止 / 误用

- **社区快餐、粉面、冒菜类不要用这套“深绿 + 白桌布 + 包厢 + 铜器”**：成本与客单对不上，会显得“装”。
- 层高不足的小店不要做深色顶棚 + 低垂吊灯，会闷。
- 没有包厢需求的门店不要留包厢，白桌布会变成负担。
- 深绿大面积使用在低照度空间会发黑；不要在暗场里做深绿 + 木。
- 不要直接复制“和谷记”字标、铜印、稻穗摄影与“五味调和/无鸡不成宴”文案。
