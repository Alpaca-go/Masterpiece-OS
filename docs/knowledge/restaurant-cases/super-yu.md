## 设计动作

1. **门头做整幅白色发光灯箱**：左侧“超级渝”字标，右侧并列“酸菜 红烧肉”品类；外圈暖橙金属/木饰面收边，嵌在深红棕木格栅墙里。
2. **入口两侧深色木饰面方柱 + 黑色石材踢脚**，柱间保持大开间，形成无门斗的开放入口（推断）；左侧木格栅墙开三条竖向橙色发光壁龛。
3. **入口内侧阶梯式米袋堆头**：白色小袋大米层层陈列，背后“米好多 吃两碗饭”发光横牌；堆头兼作入口屏风，遮挡后场视线（推断）。
4. **右侧室内整墙白底黑字书法横幅**，外圈深木格栅；左侧墙做竖幅 + 框画，让墙面成为可读的品牌面。
5. **家具统一浅木方桌 + 木凳/靠墙长凳**：桌距紧、无包间，配合白墙和暖光，形成食堂式高效率；靠背家具少，停留时间偏短（推断）。
6. **材料照明统一“深木 + 黑石 + 米白 + 暖橙”**：地面浅灰斑点面（水磨石或仿石砖未知），墙脚黑色石材压边，形成耐脏基座（推断）。
7. **橙色做物料主色**：员工围裙、打包袋、湿巾、餐具、门头侧板统一；砂锅轮廓做辅助图形，形成从空间到外带的连续识别。

## 成立前提（均为推断）

- 门面宽且方正、门头有足够高度做整幅灯箱；入口有退进或前场可放米袋堆头。
- 室内为较规则、少柱网的空间，才能形成两侧桌区 + 中间通道的食堂式排布。
- 品类是高频、认知强的家常菜，门头直接写“酸菜红烧肉”就能被看懂。
- 米饭是真实卖点，且有稳定大米供应链，才适合把米袋放在入口做陈列。
- 暖光 + 深木 + 橙色更适合重口味、晚餐、冬季场景；做清爽快餐需要降低饱和度。

## 禁止 / 误用

- 门头窄或层高不足时，不要硬做整幅大白灯箱 + 厚深木框，会把立面压小、压暗。
- 入口没有退进、消防通道不足时，不要放米袋堆头，会堵门、挡疏散。
- 不是“下饭家常菜”、米饭也不是卖点时，不要照搬“每个菜都下饭”和米袋陈列。
- 客群偏商务、安静、高客单或需要久坐时，不要用高饱和橙 + 大字书法 + 无靠背凳。
- 不要直接复制砂锅轮廓、橙色、字体和文案；只能借鉴“品类并置 + 入口堆头 + 大字墙”的结构。
