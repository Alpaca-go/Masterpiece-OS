# Masterpiece-OS 5.0.0-rc.1 — Repository Consolidation

This document is the **5.0 release-candidate consolidation report** for the
Masterpiece-OS repository. It captures the before/after state of the directory
layout, the version/lockfile changes, the file moves, the validation gates,
the branch disposition, and the real-Provider smoke procedure that gates the
final 5.0.0 cut.

## 1. Headline

- **Product version**: `5.0.0-rc.1` (single source of truth at `/VERSION`).
- **Internal package namespace**: unified to `@masterpiece/*` (was a mix of
  `@masterpiece/*` and `@masterpiece-os/*`).
- **CLI workspace**: lifted out of the repository root into
  `apps/cli/@masterpiece/cli`.
- **Desktop production path**: the official UI now exposes a single
  Short-Chain image-generation path. The Legacy / vNext mode switch has
  been removed; Legacy only exists as a migration reader.
- **Documentation tree**: rebuilt around `docs/{product,architecture,development,releases,archive/{v3.3,v4.0}}`.
- **Evaluation assets**: isolated from production under
  `evaluation/{golden-cases,anti-cases,hidden-cases,known-cases,contracts,reports}`.
- **Workspace boundaries**: 175 deep `packages/*/src/*` imports rewritten
  through `@masterpiece/*`; the `verify:workspace-boundaries` gate now fails
  hard on regressions.
- **Smoke pollution**: 9 tracked `.codex-smoke/*` files (44 MB, including a
  45 MB `app.asar`) removed from the index; data retained on disk for
  local replay, not shipped through Git.

## 5. Imports & boundaries

- 175 deep `packages/*/src/*` imports rewritten to `@masterpiece/*`.
- 14 packages now expose a `"./*": "./src/*"` wildcard export; `model-registry`
  switched to the object form.
- `verify:workspace-boundaries` (FAIL-mode for deep imports and undeclared
  subpath imports) PASSes.
- `apps/desktop/src/shared/types.ts` and
  `apps/desktop/src/main/reference-asset-inspector.ts` import subpaths
  changed from `'/index'` to `'/index.ts'` to satisfy
  `allowImportingTsExtensions: true`; downstream `tsc --noEmit` is now clean
  (see §7).

## 6. Product path

- Desktop 正式 UI 唯一保留 **Short-Chain** 视觉生成路径。
- `SettingsPanel.tsx` 不再渲染 "vNext 短链路 / Legacy 旧链路" 选项卡；
  替换为只读 "短链路（生成工作台）" 说明卡。
- `App.tsx` 不再分支到 `CreativeSessionWorkspace`（文件保留在磁盘上，
  供后续 migration 读取）。
- `vnext` / `V18` / `V6` 名称在用户可见文案中已全部清理。

### 7.3 Real Provider smoke (per exec doc §9)

| Field | Value |

| Model | e.g. `qwen3.6-plus` |

The 5.0.0 cut cannot be tagged until all three runs reach the final
report / image and the three gates stay green.
