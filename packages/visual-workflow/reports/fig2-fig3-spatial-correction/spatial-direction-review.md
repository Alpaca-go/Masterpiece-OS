## 直接替换了什么

旧确认内容不是本轮必须冻结的艺术成果。本轮替换了 **16个项目字段值**：14个文本字段，以及颜色和材料两个结构化数组；决策来源另作更新。`materialLanguage`、`colorPolicy` 两个未使用的兼容空字段仍为空。

不再以“保住复杂装置、再补商业道具”为目标。新的空间优先级是：完整前台、候客组团、服务分区与通行关系 → 开放建筑体量 → 克制艺术构件 → 小型道具。冲突时减装饰，保留功能面积。

| 字段 | 删除或改写的旧导向 | 本轮替换 |
| --- | --- | --- |
| `spatialConcept` | 展馆尺度、沿界面连续层片系统作为空间驱动 | 可运营的医美商业接待主厅；功能共同建立空间，曲面和分隔从属服务 |
| `structureLanguage` | 大型主曲面、过渡层片、从侧面连续延展上部的复杂系统 | 清楚实体建筑与入口框景，一至两处连续曲面/薄幕，安静顶面和主厅内半开放服务分区 |
| `artisticFocus` | “同一艺术系统保留局部建筑尺度的大型主曲面，以中尺度过渡层片连接局部精密薄片”等 | 建筑界面、透景、暖材料与使用关系形成艺术性，只保留局部少量轻薄分层 |
| `functionalProgram` | 服务入口主要表现为过渡门槛 | 明确员工工作、成组候客、主厅内半开放服务洽谈及受屏蔽的私密转场 |
| `functionalNetwork` | 可见门槛，但后续功能较抽象 | 到达看见前台—接近服务面—候客—小桌与成对座位的下一步服务关系，无人仍可理解 |
| `functionalRelationships` | 所有后续房间均在画外，主要剩入口边界 | 主厅内服务家具可辨，真正的私密治疗室与治疗活动仍保持画外 |
| `visibleRequirements` | 层片艺术界面与少量商业载体 | 完整可用前台、候客组团、半开放服务家具、开敞流线与无字标识面；不以道具配额替代功能 |

| `lightingLanguage` | 柔和自然光但缺少明确暖调 | 温暖、柔和、均匀漫射日光，少量暖调建筑间接光 |
| `lightingContrast` | 重点在层片边缘明暗 | 建筑、木质、软包与透光界面保持温和而可区分的体积层次 |
| `lightingInteraction` | 多尺度层片的透射光学表现 | 前台、候客及服务区均有暖光，木纹、软包与墙面可区分，局部珠光从属 |
| `lightingAvoid` | 紫色灯光与硬阴影 | 明确冷白偏蓝、玻璃发灰、过曝和抢眼独立雕塑灯具的边界 |
| `colorEntries` | 暖白乳白、浅暖灰，家具温暖层次不足 | 暖白米白背景、限定家具/局部墙面的浅木与暖中性色、仅内层很弱紫色虹彩 |
| `materialEntries` | 大型曲面—中尺度层片—局部精密薄片的多级光学系统 | 简洁半透明薄幕/隔断、暖白米白矿物基底、浅木质与暖中性软包 |
| `colorAvoid` | 主要限制紫色扩散 | 同时限制冷白单一色场、浅色层次消失与紫色家具 |
| `mustAvoid` | 13条较分散的历史禁止项 | 收敛为8条本轮偏差边界；主要纠偏来自正向字段替换，而非继续追加长清单 |
