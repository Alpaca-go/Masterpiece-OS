## Dependency constraints

- Shared Runtime must not import `electron`.
- Shared Runtime must not import `apps/desktop`.
- Desktop may import Shared Runtime through package exports.
- Desktop settings/credential/native dialog adapters remain injected host dependencies.
- `../shared/types` is currently a migration prerequisite: shared runtime contracts must own or re-export these types without depending on Desktop.
