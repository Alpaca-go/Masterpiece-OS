### 2.2 字体系统
- **标准字体**：**思源宋体（Source Han Serif）** 全字重系列，包含Light、Regular、Medium、SemiBold、Bold、Heavy共6个字重，规范明确要求不得误用其他字体。
- **品牌专用字**：「一剂良方」中文标准字为定制字形，仅用于Logo组合，不得挪作其他文字使用。
- **字体层级逻辑**：
  - 大标题：Heavy/Bold字重，黑色，重点字可替换为品牌红
  - 副标题/栏目名：Medium/SemiBold字重，黑色或棕金色
  - 正文/说明文字：Regular/Light字重，黑色或深灰色
  - 拼音/标注文字：Light字重，棕金色

### 2.3 构图规则
- Logo放置：平面物料中Logo优先放置于左上角或右上角，严格保留安全空间，除封面类物料的淡化大Logo背景外，不得居中放大作为主视觉。

- 留白规则：所有物料均保留充足留白，视觉重心偏上或偏右，整体风格简洁雅致。
- 标签类物料统一逻辑：白底+居中粗体名称+浅灰Logo底纹+棕金色辅助文字，边框为细灰线。

## 3. 设计决策与建议
### 3.1 Reference First（参考优先规则）
所有新物料设计需严格遵循以下优先级，不得突破：
1. **第一优先级**：锁定Logo资产，必须使用官方提供的原始矢量文件，不得做任何修改
2. **第二优先级**：品牌色盘，仅使用规范内的4种核心色，新增场景需从现有色值中选取，不得自定义
3. **第三优先级**：标准字体，所有文字必须使用思源宋体系列，按层级对应字重
4. **第四优先级**：排版逻辑，优先复用现有物料的成熟框架：
   - 表单类（如诊疗单）：顶部品牌色条+左上Logo+右下大Logo底纹
   - 封面类（如文件夹）：满版品牌金底+居中淡化大Logo+角落小Logo组合
   - 宣传类（如折页）：浅米/白底+水墨质感浅棕背景+品牌红重点标题+色块分区
   - 标签类：白底+居中粗体名称+浅灰Logo底纹+棕金色辅助文字

> 建议：将现有4类物料模板标准化归档，明确每个元素的坐标、色值、字体参数，后续同类物料直接调用，无需重新设计。

### 3.2 Space（空间视觉延伸建议，针对中医体验馆场景）
基于现有VI逻辑，空间视觉可直接延伸以下规则：
- **空间基底色**：以浅米灰（#E8E5E0）或白色为墙面主色，营造干净雅致的氛围
- **空间点缀色**：棕金色（#B59A6B）用于门框、导视边条、装饰线条；品牌红（#B00000）仅用于重点标识（如药房、脉诊室门牌、品牌形象墙Logo），不得大面积使用
- **导视系统**：
  - 一级导视（门头、大厅形象墙）：使用横版/竖版标准Logo组合，背景为棕金色或白色，符合深浅模式规范
  - 二级导视（诊室门牌、指引牌）：沿用标签类设计逻辑，白底+黑字+浅灰Logo底纹+细棕金边框，右上角放小型横版Logo

- **装饰元素**：墙面可使用辅助图形（四瓣花形线框）的连续排列做暗纹，或放大的浅棕色Logo作为背景墙底纹，与平面物料逻辑统一

> 注意：空间内所有Logo均需满足最小尺寸要求，保留安全空间，不得拉伸变形。

### 3.3 Packaging（包装视觉延伸建议，针对中医产品/周边）
基于现有VI逻辑，产品包装可按以下层级设计：
- **基础款包装**（如常规饮片、代用茶）：沿用标签类设计逻辑，白底+粗体产品名（思源宋体Bold）+浅灰Logo底纹+棕金色说明文字，右上角放小型横版Logo

- **小型周边**（如香囊、试用品）：使用简化的图形标+品牌名，尺寸符合最小使用规范

> 注意：所有包装不得修改Logo形态，仅可使用规范内的颜色版本，不得引入品牌色盘以外的颜色。

## 4. 限制与不确定性
1. **素材范围限制**：现有素材仅覆盖VI基础规范与4类平面印刷物料，无空间设计、包装设计、线上触点（官网/小程序/新媒体）的实际落地规范，所有延伸建议均基于平面VI逻辑推导，需结合实际场景验证。
2. **工艺材质限制**：现有素材未明确印刷工艺、材质参数（如纸张克重、烫金/UV工艺、空间材质），实际应用需额外补充规范。
3. **子标识不确定性**：Logo右上角的「素问」小印章的定位（文化符号/子品牌/系列名）未明确说明，现有规范仅显示其与主Logo的组合位置，暂不建议单独使用。
4. **字体版本限制**：规范明确标注需使用指定版本的思源宋体，未明确是否可使用其他衬线字体作为替代，跨平台使用时需注意字体版权与版本一致性。
5. **动态场景限制**：现有规范仅明确印刷场景的Logo使用规则，未明确动态媒介（如视频、交互界面）的Logo使用规范。
