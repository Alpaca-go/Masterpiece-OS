# Visual analysis authority

This directory contains only files used by current offline release verification.

- `current-verification/evaluation-corpus.md` is the frozen evaluation corpus.
- `current-verification/evaluation-rubric.md` is the frozen evaluation rubric.

Stage reports, provider comparisons, human-review bundles, generated evaluation
results, and freeze-era manifests are historical evidence. They are kept locally
under `local-archive/versioned-workflow/docs/visual-analysis/`, which is ignored
by Git and does not participate in either current product flow.
